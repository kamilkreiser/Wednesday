# Five Skills Pack

Version: 2.0 — Portable Edition

## What this is

Five self-contained starter skills you can use without access to anyone else’s computer, vault, or folder structure.

## Included

- `reddit-trends.md`
- `leadmagnet.md`
- `linkedin-post.md`
- `content-writer.md`
- `skill-creator.md`

## Fastest way to use them

Open any file, give it to your AI coding agent, and say:

> Follow this skill for my next request.

Each file contains its complete workflow. None of them need files from Eric’s machine.

## Install as reusable skills

If your agent supports project skills, create one folder per skill and copy the matching file into it as `SKILL.md`.

Example:

```text
<your-project>/
  .pi/
    skills/
      reddit-trends/
        SKILL.md
      leadmagnet/
        SKILL.md
```

For another agent or harness, use its advertised project-skill directory instead. Keep the same one-folder-per-skill structure.

## Suggested order

1. `reddit-trends.md`
2. `leadmagnet.md`
3. `linkedin-post.md`
4. `content-writer.md`
5. `skill-creator.md`

## Portability rules

- Paths are relative to your own project.
- Outputs go into the current working directory unless you provide another location.
- Optional voice/context files are used only when you explicitly provide them.
- No workflow depends on Eric’s EMAI vault.
