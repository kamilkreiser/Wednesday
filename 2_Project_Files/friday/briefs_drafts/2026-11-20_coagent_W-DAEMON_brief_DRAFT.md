  - **The pure rule.** `pub fn win_data_dir_rule(profile: &str, data_dir: &str) -> Result<(), WinDirRefusal>` in `src/datadir.rs`, with no `cfg` on it, so its tests run here. `WinDirRefusal` is a new public enum of categories (no path text inside it), with a `Display` of fixed words.
    1. Each of the two inputs is parsed the same way. It must be non-empty and hold no character below U+0020. It must begin with one ASCII letter, then `:`, then `\` or `/`. Everything else is refused: a network path (`\\server\share`), a device or long-path prefix (`\\?\`, `\\.\`), a drive-relative path (`C:name`), a path with no drive (`\name`), a relative path.
    2. The rest is split on `\` and `/` alike. One trailing separator is allowed. Any other empty component (a doubled separator) is refused.
