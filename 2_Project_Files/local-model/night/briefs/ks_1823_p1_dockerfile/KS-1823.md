## What is wrong (one paragraph)

The api-gateway Dockerfile builder stage runs `COPY docs/openapi/ ./docs/openapi/` (`Dockerfile:32`) and the runtime stage copies that directory on (`COPY --from=builder /app/docs/openapi ./docs/openapi`, `:69`). The gateway reads only `docs/openapi/secuura-api.yaml` (`api-gateway/src/index.ts:590-592`), and a search of its non-test source for `express.static` finds nothing, so this is hygiene, not a stated exposure. The smallest fix is one `RUN rm -f` line right after that COPY removing exactly the two name shapes (`*.pre-*`, `*.rollback-*`) inside `docs/openapi`; the two markdown files kintsugi carries and the spec stay. No TypeScript changes.
