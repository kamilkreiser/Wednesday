## What is wrong (one paragraph)

Two comments in `services/originate/src/routes/certifications.ts` (the KS-1633 block above `reserveCertificationRow`) say something the code does not do. (1) `:520` says writing the row first "removes the window rather than narrowing it". It narrows it: when the reservation itself fails the request proceeds and the anchor-then-fail path (an orphan anchor) is unchanged, which the code's own comment says a few lines further down (`:571-572`, "when the reservation itself fails the request proceeds and an orphan anchor can still be created"). (2) `:527` says the provisional row under-claims for "the sub-second window before the second write". The second write comes after the anchoring call, which is bounded by `AbortSignal.timeout(10000)` (`:616`), so the window is up to 10 seconds. Both were corrected in PR #1623's body and deliberately left in the code; they are wrong in the merged tree.
