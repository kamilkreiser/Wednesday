## What is wrong (one paragraph)

Line 82 of the script builds the first alternative of the gate's pattern. Between the docker verb and the `akto-` name it allows any number of dash-tokens, `([[:space:]]+-[^[:space:]]+)*`. A flag that takes a SEPARATE value (`-u root`, `-e FOO=1`, `--tail 5`) puts a non-dash word (`root`, `FOO=1`, `5`) between two of those tokens, which breaks the chain, so `docker exec -u root akto-mongo mongosh` and `docker logs --tail 5 akto-testing` exit 0 (not reported) although they target slot 1. The fix lets each dash-token be followed by ONE optional non-dash word: `([[:space:]]+-[^[:space:]]+([[:space:]]+[^-[:space:]][^[:space:]]*)?)*`. Measured with the real script in a scratch copy: all four value-flag forms exit 1 after the fix, the AKTO_PREFIX form after a flag and its value stays exit 0.
