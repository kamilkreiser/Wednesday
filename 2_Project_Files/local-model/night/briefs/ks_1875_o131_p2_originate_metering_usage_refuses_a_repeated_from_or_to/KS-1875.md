## What is wrong (one paragraph)

In `Blockchain/Dev/services/originate/src/routes/metering.ts` the usage handler (line 108) reads the window bounds as `const from = typeof req.query.from === 'string' ? req.query.from : undefined;` and the same for `to` (lines 117-118). When a bound is REPEATED in the query string (`?from=2026-01-01&from=2026-02-01`), Express parses it as an array, `typeof` is not `'string'`, the bound becomes `undefined`, and the call goes on to `getUsageSummary(tenant, undefined, to)` and answers 200 with that side of the window OPEN: a wider read than the caller asked for. The fix: a repeated `from` or `to` is refused with the route's existing 400 BAD_REQUEST shape and the usage query is never made.
