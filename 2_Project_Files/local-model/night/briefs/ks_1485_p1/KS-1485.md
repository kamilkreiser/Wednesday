## What is wrong (one paragraph)

`authoritativeTxHash(anchor)` in originate's `anchorStateSync.ts` returns the first of `transactionHash`, `txHash`, `transactionId` that is a non-empty string, unless it starts with a dev-mode placeholder prefix, in which case it returns null (a placeholder is not an on-chain transaction; the KS-522 honest-labelling family). It tests `tx_` and `mock_tx_` only. The non-production batch mock in the anchoring service writes `mock_batch_tx_...` hashes, which therefore pass as real in all three decisions that call the function. The fix is a third `startsWith` test on the same line.
