## What is wrong (one paragraph)

`GitHubProvider.exchange` (`services/auth/src/providers/social/github.ts:63`) POSTs to GitHub's token endpoint and handles only a non-2xx answer (`:79-84`). GitHub answers a bad or expired code with HTTP 200 and an `{error, error_description}` body, so the next line (`:86`), `const { access_token } = (await tokenRes.json()) as { access_token: string };`, reads `undefined` and `:88-91` calls `https://api.github.com/user` with `Authorization: Bearer undefined`. The only thing that stops the sign-in is GitHub answering that 401 (the adapter then throws 'Failed to fetch GitHub user profile'). Refuse a token answer with no usable `access_token` (or one carrying an `error` field) as a token-exchange failure, before any profile call.
