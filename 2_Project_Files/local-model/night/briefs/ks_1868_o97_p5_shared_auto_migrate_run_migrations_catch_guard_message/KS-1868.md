## What is wrong (one paragraph)

The per-migration catch of `runMigrations` reads the thrown value (`${err.message || err}`) with no guard. A thrown value whose read throws (a revoked Proxy: any property read and `instanceof` throw on it; an Error whose `message` getter throws) makes the catch itself throw, so `runMigrations` REJECTS (after the `finally` closes the pool) and the caller gets no result, where an ordinary failure is recorded in `errors` and the loop stops. The fix is the house guard placed in the catch: read the value inside its own `try` and fall back to the constant `'unreadable thrown value'` when the read throws. The text of every value that can be read is unchanged.
