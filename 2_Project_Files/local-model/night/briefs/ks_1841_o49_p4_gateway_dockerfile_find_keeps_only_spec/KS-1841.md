## What is wrong (one paragraph)

`Dockerfile:32` copies the whole `docs/openapi/` directory into the builder stage and the runtime stage copies it on (`:71`). `Dockerfile:35` then runs `rm -f ./docs/openapi/*.pre-* ./docs/openapi/*.rollback-*`, which removes two name shapes only. The gateway reads `docs/openapi/secuura-api.yaml` and nothing else in that directory (`src/index.ts:590-592`), so every other file the host directory holds (a `.bak`, `~`, `.orig`, an editor swap file, a prefixed copy, a stray note such as `WORKFLOWS.md`, a sub-folder) is baked into the image for no reason. The fix replaces the line with a `find` over the directory that deletes every direct entry except `secuura-api.yaml`. It is one level deep (`-mindepth 1 -maxdepth 1`), uses `rm -rf` for entries that are folders, and exits 0 when there is nothing to delete.
