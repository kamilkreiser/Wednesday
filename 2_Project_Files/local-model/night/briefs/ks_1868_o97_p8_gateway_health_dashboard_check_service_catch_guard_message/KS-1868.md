## What is wrong (one paragraph)

The catch of `checkService` reads the thrown value (`instanceof DOMException`, `.name`, `instanceof Error`, `.message`) with no guard. A thrown value whose read throws (a revoked Proxy: any property read and `instanceof` throw on it; an Error whose `message` getter throws) makes the catch itself throw, so `checkService` rejects, the aggregate silently drops the settled-rejected result, and the service is ABSENT from the dashboard instead of reported down. The fix is the house guard placed in the catch: read the value inside its own `try` and fall back to the constant `'unreadable thrown value'` when the read throws. The text of every value that can be read is unchanged.
