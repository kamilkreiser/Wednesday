## What is wrong (one paragraph)

`GET /api/system-errors` (`systemErrors.ts:182-201`) wraps its work in a try; its catch is `if (err instanceof z.ZodError) { return res.status(400)... }` and then `fail500(res, 'Error list read failed (GET /api/system-errors)', err);`. `instanceof` reads the thrown value's prototype. If the service call rejects with a revoked Proxy, or with a Proxy whose `getPrototypeOf` trap throws, that check itself throws from inside the catch, before `fail500` is reached; the async handler's promise rejects and the request gets NO response (Gate B measured this for these values; `fail500` itself already survives them since KS-1772, and the sibling routes whose catch goes straight to `fail500` answer 500). The change is a small local helper `isZodError(err)` that does the `instanceof` inside its own try and answers false when the check throws, and the catch calls it. A value that cannot be inspected is not a ZodError, so it falls through to `fail500` and gets the constant 500.

## Where

- Directly above the comment line `/** List errors with optional filters - admin only (dev: open) */` (`:181`) - **must change**: the new helper `isZodError` (a doc comment, a ten-line function, one trailing blank line) is INSERTED; nothing else moves.
- `:196` - **must change**: `    if (err instanceof z.ZodError) {` becomes `    if (isZodError(err)) {` (the body of the `if` is unchanged; `err` is `any` in that catch, so `err.errors` still type-checks).
