## What is wrong (one paragraph)

In `index.ts` `verifyDbReady` (called once at boot from `initDb().then(async (connected) => { if (connected) await verifyDbReady(); })`, line 1281) runs `SELECT COUNT(*) AS cnt FROM svc_kyc_verifications` and, in its catch, logs `logger.warn('KYC DB verification query failed', { error: err?.message })` (line 505) and returns nothing. If the query rejects with a revoked Proxy, `err?.message` itself throws a TypeError inside the catch block (property reads on a revoked Proxy throw); if it rejects with an Error whose `message` getter throws, `err?.message` throws. Either way the catch throws before the line is logged, `verifyDbReady` rejects, and the boot callback's promise has no handler (an unhandled rejection, process-fatal on Node >= 15). The fix keeps the log line's text and replaces only the value: it first reads the SAME expression `err?.message` into a local `reason` inside its own `try`, and a `catch` sets the constant `'unreadable thrown value'`; the log line then uses `{ error: reason }`. This is the inline guard already merged in the same file (lines 191-198 etc.); no helper is added.
