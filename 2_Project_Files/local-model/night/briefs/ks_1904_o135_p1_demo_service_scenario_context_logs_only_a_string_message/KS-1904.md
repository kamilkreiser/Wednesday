## What is wrong (one paragraph)

In `Blockchain/Dev/services/demo-service/src/routes/scenario.ts` the catch of the `GET /scenario/context` handler (lines 112 to 122) guards a message read that THROWS (KS-1868: the inner try at lines 114 to 118) but not a read that RETURNS a non-string: line 115 is `      message = err instanceof Error ? err.message : 'Unknown error';`. For an Error whose `message` getter returns an object with a throwing `toJSON`, `message` is that object, the logger is handed `{ error: <object> }` (line 119), and JSON.stringify of that meta throws (QA gate 60 reproduced it on the same guard expression in other services). Priority Low: nothing known throws this shape. The fix: coerce any message that is not a string to the constant reason already used in the inner catch.
