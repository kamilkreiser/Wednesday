## What is wrong (one paragraph)

Line 17 of smoke-test.sh is `echo "Smoke target: $GATEWAY"`. `GATEWAY` is `${SMOKE_BASE_URL:-http://localhost:6882}`, so a base URL carrying credentials, such as `https://alice:s3cr3t-token@smoke-target.invalid:9999`, is printed whole as the first line of output, and so into a terminal and any CI log. The fix prints the same URL with the `user:password@` part removed, using `sed -E` (`s#^([A-Za-z][A-Za-z0-9+.-]*://)[^/@]*@#\1#`), and adds one comment line above. `GATEWAY` itself is NOT changed: every request still goes to the full URL. Measured in a scratch copy: the suite with the three new cells is 6 passed, 2 failed at the tip (the two RED cells) and 8 passed, 0 failed with the edit, on macOS bash 3.2 and BSD sed.
