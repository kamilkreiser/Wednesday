## What is wrong (one paragraph)

In `Blockchain/Dev/services/analytics/src/services/metricsCollector.ts` the catch of `MetricsCollector.loadFromDb` (lines 490 to 501) guards a message read that THROWS (KS-1868: the inner try at lines 492 to 496) but not a read that RETURNS a non-string: line 493 is `        reason = err instanceof Error ? err.message : String(err);`. For an Error whose `message` getter returns an object with a throwing `toJSON`, `reason` is that object, the logger is handed `{ error: <object> }` (lines 498 to 500), and JSON.stringify of that meta throws (QA gate 60 reproduced it on the same guard expression in other services). Priority Low: nothing known throws this shape. The fix: coerce any message that is not a string to the constant reason already used in the inner catch.
