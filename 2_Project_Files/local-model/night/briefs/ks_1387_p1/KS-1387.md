## What is wrong (one paragraph)

`services/governance/src/routes/governance.ts` declares its router as `const router = Router();`, leaving the exported type to inference. This service's tsconfig emits declarations (`declaration: true`), and when `@secuura/shared` brings its own `@types/express-serve-static-core` the compiler cannot name the inferred type in the `.d.ts` it must write, so `npm run build` stops with TS2742 and a clean image build fails. An explicit annotation, `const router: Router = Router();`, gives the compiler a name it can write. Nothing else in the file changes and no behaviour changes.
