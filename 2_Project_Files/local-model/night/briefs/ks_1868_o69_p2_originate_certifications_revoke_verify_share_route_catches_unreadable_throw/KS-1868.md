## What is wrong (one paragraph)

In `routes/certifications.ts` the catch blocks of POST /:id/revoke (line 1168), POST /:id/verify (line 1234) and POST /:id/share (line 1333) each log `logger.error('<context>', { error: error instanceof Error ? error.message : String(error) })` (lines 1169, 1235, 1334) and then answer a constant 500 (`Failed to revoke certification`, `Failed to verify certification`, `Failed to share certification`). If the call before it rejects with a revoked Proxy, `error instanceof Error` itself throws a TypeError inside the catch; if it rejects with an Error whose `message` getter throws, `error.message` throws. Either way the catch throws, nothing is logged and the request gets no answer. The fix keeps each log line's text and replaces only the value: it first reads the same expression into a local `reason` inside its own `try`, and a `catch` sets the constant `'unreadable thrown value'`; the log line then uses `{ error: reason }`. The constant 500 answers are untouched. This is the inline guard already merged in the same file (GET /:id catch, lines 1086-1094); no helper is added.
