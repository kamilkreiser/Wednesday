## What is wrong (one paragraph)

The catch of `enableWallet` reads the thrown value (`error instanceof Error ? error.message : 'User rejected'`) with no guard. A thrown value whose read throws (a revoked Proxy: any property read and `instanceof` throw on it; an Error whose `message` getter throws) makes the catch itself throw, so the call rejects with the engine TypeError or the getter error, not with the documented `Failed to enable wallet <name>: <reason>` Error that callers match on. The fix is the house guard placed in the catch: read the value inside its own `try` and fall back to the constant `'unreadable thrown value'` when the read throws. The text of every value that can be read is unchanged.
