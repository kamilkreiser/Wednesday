## What is wrong (one paragraph)

In `scheduledJobs.ts` the catch block of `loadScheduledJobsFromDb` (line 149) logs `logger.warn('loadScheduledJobsFromDb failed — starting with defaults only', { error: err instanceof Error ? err.message : String(err) })` (the read is on line 151). If a query rejects with a revoked Proxy, `err instanceof Error` itself throws a TypeError inside the catch block; if it rejects with an Error whose `message` getter throws, `err.message` throws. Either way the catch throws before the WARN is emitted: `loadScheduledJobsFromDb()` rejects (it is one of the startup loaders in `index.ts`) instead of starting with defaults. The fix reads the thrown value inside its own inner `try` into a local `reason`, falling back to the constant `unreadable thrown value`, and the WARN uses `reason`. Nothing else changes: an ordinary Error still logs `{ error: <its message> }` and the log text is unchanged.
