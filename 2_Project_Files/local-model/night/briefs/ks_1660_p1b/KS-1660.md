## What is wrong (one paragraph)

In the derived-document build (`:640-668`), `const { versionedById: droppedVersionedById, ...dataWithoutVersionedById } = data` removes the caller's `versionedById` (KS-1508), then the derived `data` is `{ title, certificationId, certifiedAt, parentDocumentId, ...dataWithoutVersionedById }`: the server's `parentDocumentId` is written first and the caller's spread overwrites it. The fix: also take `parentDocumentId: droppedParentDocumentId` out in the same destructure (so it is not in the rest object), and log when one was supplied, naming only the tenant and the actor, never the value. The variable name `dataWithoutVersionedById` stays as it is. The rest of the function is unchanged. The `contentHash` expression further down still reads the caller's unstripped `data`; that is KS-1537 N-4 and is NOT changed here.
