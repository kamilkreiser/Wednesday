## What is wrong (one paragraph)

`insertCertificationRow` (`certificationRepo.ts`) computes `const issuerUserId = toActorUuid(cert.issuer.id);` (KS-564) and binds `${issuerUserId}::uuid` to `issuer_user_id`, but binds the holder as `${cert.holder.id}::uuid` to `owner_user_id` with no fold. The route defaults the holder to the caller (`holderId = req.body.holderId || issuer.id`), and for a connector caller that is the principal string `connector:platform-s:<uuid>`, which is not a UUID: Postgres throws 22P02 and the route answers 400 "Certification payload contains values that cannot be stored" for a payload that is fine. The fix is the one line: bind `${toActorUuid(cert.holder.id)}::uuid`. `toActorUuid` returns the value when it is a UUID and `null` otherwise, and `owner_user_id` is nullable (migration 043's comment: it "has always been nullable for exactly this reason"). `toActorUuid` is already imported in this file. Nothing else changes.
