## What is wrong (one paragraph)
`Blockchain/Dev/scripts/run-migrations.sh` lines 71 and 72 cut the host and the port out of DATABASE_URL with `sed -E 's|...|\1|'` and no `-n`. When the pattern does not match, sed prints the input line unchanged, so the variable holds the whole URL, never empty. A URL with no port (`postgresql://u:pw@db.example/secuura`) gives host `db.example` and a port equal to the whole URL; line 73 `PG_PORT=${PG_PORT:-5432}` can therefore never apply; a hostless URL gives both variables equal to the whole URL. `pg_isready -h "$PG_HOST" -p "$PG_PORT" -q` (line 76) then never succeeds, the loop runs its 30 attempts at 2 seconds, and the runner exits 2 after about 60 s with "PostgreSQL did not become ready" although the database may be fine. Measured by the filing seat on the two sed commands (BSD sed) and re-measured here by running the real script against the three URL shapes with a recording pg_isready stub (tip: the cells below read `[-p][<whole URL>]`).
