## What is wrong (one paragraph)

`fail500` (`:93`-`:96`) logs a thrown value with `err instanceof Error ? err.message : String(err)`. For a thrown plain object `String(err)` is `[object Object]`, so the log loses what was thrown. The first fix (#1296) used `util.inspect`, which writes every VALUE into the log, secrets included, so it was held. The ruled rule:
- an Error logs its message (unchanged);
- a string logs itself (unchanged);
- an object logs `thrown <ConstructorName> with fields [<key>, <key>]`, and anything else logs `thrown <typeof>`.
Keys only, never values.
