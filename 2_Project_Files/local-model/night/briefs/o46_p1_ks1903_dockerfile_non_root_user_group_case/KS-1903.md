## What is wrong (one paragraph)

`check-dockerfile-non-root.sh:27` reads the last `USER` value of each Dockerfile and `:32` tests it with `= "root"` or `= "0"` only. So a final `USER root:root`, `USER 0:0` or `USER ROOT` is read as `root:root`, `0:0` or `ROOT`, matches neither, and the gate prints `OK` for a container that runs as root. Measured in the ticket with the real script: `USER root` rc 1 (reported), `USER app` rc 0, but `root:root`, `0:0` and `ROOT` all rc 0 `OK`. The fix is two lines after the line that reads the value: drop any `:group` suffix, then lowercase it, so every spelling reaches the existing comparison as `root` or `0`.
