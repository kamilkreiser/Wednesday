## What is wrong (one paragraph)

`GET /api/document-types` (the public document-types list, no auth) reads every document type from Redis inside a try. When that read throws, the catch at `:1579` answers a constant 500 and does nothing with `err`, so a Redis outage or a bad record leaves no trace in the gateway log, and ESLint flags `err` as unused. The router already receives a structured `log` (a dependency, `log: (level, message, meta?) => void`) and uses it for the same purpose elsewhere in this file, e.g. `:1421` logs `{ error: err instanceof Error ? err.message : String(err) }`. The fix adds that one call, in that shape, before the 500. The client still gets the same constant body.
