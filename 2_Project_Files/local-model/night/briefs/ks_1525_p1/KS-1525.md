## What is wrong (one paragraph)

`rowToApiKey` (`converters.ts:156-179`) maps `isActive: Boolean(r.is_active)` (`:171`). That is right for every value the gate fed it: an absent column (`undefined` becomes `false`), `null` (`false`) and the Postgres text form `'t'` (`true`). But nothing in `row-converters.test.ts` or the rest of the suite asserts it, so the gate's mutant G1 (`is_active` absent gives `isActive: true`) passed all 311 security tests, and so did G10 (`isActive: r.is_active === true`, which would read the text `'t'` as inactive). G1 is the dangerous one: it silently un-revokes a key whose column is missing. The fix is three cells appended inside the existing `describe('rowToApiKey()')`, using the file's own `KEY_ROW` constant.
