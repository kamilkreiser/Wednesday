## What is wrong (one paragraph)

The catch around `mod.request(...)` in `safeOutboundRequest` reads the thrown value's `message` with no guard. A thrown value whose read throws (a revoked Proxy: any property read and `instanceof` throw on it; an Error whose `message` getter throws) makes the catch itself throw, so the call REJECTS (the throw escapes the Promise executor) where the function documents that it returns a tagged `request_failed` result rather than throwing (KS-931). The fix is the house guard placed in the catch: read the value inside its own `try` and fall back to the constant `'unreadable thrown value'` when the read throws. The text of every value that can be read is unchanged.
