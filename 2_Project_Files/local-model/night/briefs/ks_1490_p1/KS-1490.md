## What is wrong (one paragraph)

`verify.ts` takes its base URL once, at `:4`, as `process.env.SECUURA_API_URL || 'https://demo-pk.secuura.net'`, and `verifyHash` builds the request at `:17` as `` `${SECUURA_API_URL}/api/verification/verify` ``. An operator who writes the override with a trailing slash (`https://host/`) therefore gets `https://host//api/verification/verify`. The fix strips trailing slashes from the base where it is defined (`.replace(/\/+$/, '')`), so every use of it, `:17` included, gets a base with none. The default has no trailing slash, so the unset case is unchanged, and a base with a path keeps its path.
