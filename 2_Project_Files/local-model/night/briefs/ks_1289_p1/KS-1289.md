## What is wrong (one paragraph)

`Blockchain/Dev/.dockerignore` line 13 is the single line `tests`. A .dockerignore pattern is matched against paths relative to the build-context root, so `tests` matches only a top-level `tests/` directory; it does not match `services/api-gateway/src/__tests__/` or any other nested `__tests__`, which differ in name anyway. docker-compose builds every service with `context: .` (31 `context: .` lines in `Blockchain/Dev/docker-compose.yml`, counted) with that directory as the root, so this file is the effective ignore file. The measured cost on the ticket: two files under `packages/shared/src/__tests__/` were the only changed input for 23 of 29 rebuilt images on the 2026-09-23 deploy. The fix is one new line `**/__tests__` (the `**/` prefix is what makes it match at any depth, as the file's own line 2 `**/._*` does), placed directly after `tests`.
