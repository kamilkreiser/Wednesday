## What is wrong (one paragraph)

In originate `routes/documents.ts` the outer catch of POST /:id/sign, POST /:id/sign-cert and POST /:id/sign-wallet logs `{ error: error instanceof Error ? error.message : String(error) }` with the read written inline in the argument, with no guard. A thrown value whose read itself throws (a revoked Proxy makes `instanceof` throw; an Error whose `message` getter throws) throws INSIDE the catch, and an Error whose `message` getter returns a hostile non-string (a revoked Proxy, a null-prototype object, a Symbol) is passed on uncoerced to the logger; in an async Express 4 handler the route then never answers and Node sees an unhandled rejection. The fix gives each catch the guard the sibling originate routes (`routes/anchors.ts`, `routes/signatories.ts`) already carry, with the coercing read: `let reason: string; try { reason = String(error instanceof Error ? error.message : error); } catch { reason = 'unreadable thrown value'; }` and `logger.error(..., { error: reason })`. The three catches are otherwise unchanged (the same 500 INTERNAL_ERROR body).
