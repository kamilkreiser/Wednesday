## What is wrong (one paragraph)

In `routes/verification.ts` the public, no-login `POST /api/verification/verify-file` catch logs 'File verification error' and answers 500 'File verification failed'. The guard (KS-1868 O66/O70, merged in PR 1925) reads `reason = X instanceof Error ? X.message : String(X);` inside a local `try` and falls back to the constant `'unreadable thrown value'` when that throws. The fix is one token per site: `reason = String(X instanceof Error ? X.message : X);`, which turns an object into its string form and sends a value String() cannot read to the existing fallback.
