## What is wrong (one paragraph)

The catch of `verifyDocumentAnchor` reads the thrown value (`error instanceof Error ? error.message : 'Unknown error'`) with no guard. A thrown value whose read throws (a revoked Proxy: any property read and `instanceof` throw on it; an Error whose `message` getter throws) makes the catch itself throw, so the call REJECTS where an ordinary failure answers `{ verified: false, error }`. The fix is the house guard placed in the catch: read the value inside its own `try` and fall back to the constant `'unreadable thrown value'` when the read throws. The text of every value that can be read is unchanged.
