## What is wrong (one paragraph)

In `demo-service/src/index.ts` the boot gate is `try { assertDemoServiceEnabled(); } catch (err) { const message = err instanceof Error ? err.message : String(err); logger.error(`FATAL: ${message}`); process.exit(1); }`. If the thrown value is a revoked Proxy, `err instanceof Error` itself throws (a TypeError, "Cannot perform 'getPrototypeOf' on a proxy that has been revoked"), inside the catch block, so the FATAL line is not logged and `process.exit(1)` is not reached. The fix reads the thrown value inside its own inner `try` and falls back to the constant `unreadable thrown value`. Nothing else changes: an ordinary Error still logs `FATAL: <its message>`.
