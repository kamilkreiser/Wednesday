## What is wrong (one paragraph)

`GET /api/webhooks` (`webhooks.ts:179`-`:202`) runs its list query as `const rows = await db.$queryRaw\`...\`` (`:191`-`:196`) and chains `.catch((e: any) => { logger.warn('webhooks list query failed', { error: e?.message }); return []; })` onto it (`:196`).
