## What is wrong (one paragraph)

In `state.ts` the catch block of the `GET /state` handler (line 80) does `const message = err instanceof Error ? err.message : 'Unknown error'` (line 81), then `logger.error('Failed to read demo state', { error: message })` and `return res.json(inMemoryState)`. If Redis rejects with a revoked Proxy, `err instanceof Error` itself throws a TypeError inside the catch block; if it rejects with an Error whose `message` getter throws, `err.message` throws. Either way the catch throws before the log and before the fallback answer: the async handler rejects, no ERROR is logged, and the request gets no in-memory fallback. The fix reads the thrown value inside its own inner `try` into `message`, falling back to the constant `unreadable thrown value`. Nothing else changes: an ordinary Error still logs `{ error: <its message> }` and the handler still answers `res.json(inMemoryState)`.
