## What is wrong (one paragraph)

`classifyThreadMintError` reads `err?.message` (falling back to `String(error)`) and `err?.code` with no guard. `?.` guards null and undefined only: a revoked Proxy throws on both reads, and an Error whose `message` getter throws throws on the first, so `classifyThreadMintError` THROWS from inside the route's catch, where an ordinary Error is classified (503, 400) or left unclassified (null, the route keeps its 500). The fix is the house guard: read both inside one `try` and, when the read throws, return `null` (an unreadable value is an unclassified failure). The classification of every value that can be read is unchanged. FORM OF THIS BRIEF: the probe form.
