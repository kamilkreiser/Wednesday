## What is wrong (one paragraph)

In `POST /api/certifications/:id/recertify` the route posts the verification certificate's anchor to anchoring's `POST /api/anchors` (`:1368-1382`) and then checks only `if (upstream.ok) { ... }` (`:1383-1387`), with no `else`. A refusal is an answer, not an exception, so the `catch` at `:1388` never sees it and nothing is logged. The fix: after the `if` block's last line (`:1386`, `anchoringStatus = 'submitted';`), close the `if` with `} else {`, read the body as text (never throwing), and `logger.warn` one line naming the new certificate id, the original certification id, the status and the first 200 characters of the body. The existing `}` at `:1387` then closes the `else`.
