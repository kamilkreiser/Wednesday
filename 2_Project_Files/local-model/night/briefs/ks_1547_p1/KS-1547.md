## What is wrong (one paragraph)

`step()` in `preflight.sh` reads the leg total out of its header (`step "3/16  Title"`) and aborts the whole preflight when that total disagrees with `TOTAL_LEGS` (KS-1046). Line 225 takes everything after the `/` and then cuts it at the first SPACE (`${_hdr_total%% *}`). A header whose total is followed by a TAB or a colon (`3/16<TAB>Title`, `3/16:Title`) keeps that tail, so `16<TAB>Title` is compared with `16`, the comparison fails, and the preflight prints `PREFLIGHT ABORTED` blaming a header count that is correct. Cutting at the first NON-DIGIT keeps exactly the number. Latent today: all 16 `step` headers have a space after the denominator.

set -uo pipefail

HERE="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
PREFLIGHT="$HERE/../preflight/preflight.sh"
PASS=0
FAIL=0

expect() {
  local desc="$1" want="$2" got="$3"
  if [[ "$got" == "$want" ]]; then
    PASS=$((PASS + 1)); printf 'ok   %s\n' "$desc"
  else
    FAIL=$((FAIL + 1)); printf 'FAIL %s\n       want "%s", got "%s"\n' "$desc" "$want" "$got"

# call_step <header>: one call to the script's own step(), then a marker line.
# Sets RC and writes $tmp/out.txt.

    cat "$tmp/helpers.sh"

  bash "$tmp/run.sh" > "$tmp/out.txt" 2>&1
