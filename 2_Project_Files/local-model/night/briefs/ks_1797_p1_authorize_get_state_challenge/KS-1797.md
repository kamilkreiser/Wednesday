## What is wrong (one paragraph)

`GET /api/oauth/authorize` (the handler at `services/auth/src/routes/oauth.ts:487`) reads its query as `req.query as Record<string, string>` (`:492`). The cast does nothing at run time, so `?state=a&state=b` or `?code_challenge=a&code_challenge=b` reaches the handler as an ARRAY. `generateConsentPage` then calls `escapeHtml(params.state)` and `escapeHtml(params.codeChallenge || '')` (`:1522`, `:1523`) and `escapeHtml(s)` is `s.replace(...)` (`:1582`), which an array does not have: the call throws and the handler's catch answers 500 `server_error`. KS-1219 closed the same class for `scope` (`:396`); a repeated `code_challenge_method` is already a 400 by accident. A malformed request is a 400 `invalid_request`, the message the file already uses.
