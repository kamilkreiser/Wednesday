## What is wrong (one paragraph)

`warnNoAllowance(throttleKey, principal, tenant, authMethod)` builds one `console.warn` line: principal and tenant go through `logField` (KS-1480: JSON-string escaping plus NEL, DEL, the C1 controls and the Unicode line and paragraph separators), but `authMethod` is interpolated raw. It is safe today only because the gate in front of it, `MACHINE_AUTH_METHODS.has(user.authMethod)`, admits exactly `api_key` and `oauth_app`; widening that set, or any path that lets a different string through, would let a value with a newline split or forge a log line. The call site passes `String(user.authMethod)`; passing `logField(user.authMethod)` instead escapes the field before it reaches the template, with no change for the two real values.
