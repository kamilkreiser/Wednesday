## What is wrong (one paragraph)

Two catches of `MilestoneService` pass `err?.message` straight into the logger's meta object, unguarded. `?.` guards a null or undefined value only: a thrown value whose read throws (a revoked Proxy: the `.message` get throws; an Error whose `message` getter throws) makes the catch THROW, so `checkAndAwardMilestones` REJECTS after it has computed the awards, where an ordinary Error gets a logged failure and the awarded milestones and rewards are still answered (the failed save is swallowed by design). The fix is the house guard placed before each logger call: read the message once inside a `try` (`?.` kept), keep `undefined`/`null` as they are, coerce anything else with `String(...)`, fall back to the constant `'unreadable thrown value'` when the read or the coercion throws; then `error: reason`. The one-line catch at line 180 becomes a block (the logger call and its message text unchanged). The three READ catches of this file (lines 124, 159, 238) are a separate brief (O90-P4) and untouched here.
