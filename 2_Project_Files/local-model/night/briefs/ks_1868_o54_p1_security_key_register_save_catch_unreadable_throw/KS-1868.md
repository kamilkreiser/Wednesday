## What is wrong (one paragraph)

In `index.ts` the `POST /api/keys` handler saves the new key inside a `try` (a rotate through `saveKeyAndRetirePriors`, otherwise `dbSaveApiKey`). Its `catch (saveErr: any)` first drops the in-memory key, then classifies the failure with `const infra = isInfrastructureDbError(saveErr);` (line 1413; that helper reads `err.code` and `err.message`, :1150-1152) and logs the KS-888 line with `code: saveErr?.code` (line 1414), then answers 503 (infrastructure) or 500 with `The API key could not be saved, so no key was issued`. If the INSERT rejects with a revoked Proxy, any property read throws a TypeError inside the catch block; if it rejects with an Error whose `message` getter throws, `isInfrastructureDbError` throws on `e?.message`. Either way the catch throws before the log line and before its JSON answer, so the KS-888 line is lost and the request falls through to the generic error path. The fix computes `infra` (starting `false`) and `code` inside an inner `try` and, when the value cannot be read, leaves them at `false` and `undefined`; the log call uses the local `code`. An ordinary Error is unchanged (its `code` is still logged and still classified).

The catch only runs on the rotate path in practice (`saveKeyAndRetirePriors` rethrows the raw value out of `transaction()`); `dbSaveApiKey`'s own catch reads `err?.message` first (a different read, not touched). **BEHAVIOUR CHANGE the raise PR must state:** when the rotate INSERT rejects with an unreadable value, the route today logs NO `KS-888: API key mint refused` line and answers 500 with the generic `An unexpected error occurred` (gate 90, G90-F4: no key issued, nothing committed, ROLLBACK, no unhandled rejection); after the fix it logs the KS-888 line (`infra: false`, no code) and answers 500 INTERNAL_ERROR `The API key could not be saved, so no key was issued`, which is exactly what an ordinary non-infrastructure Error already gets. Status stays 500, fail-closed is unchanged, and no 503 is produced for an unreadable value (it cannot be classified as infrastructure).
