## What is wrong (one paragraph)

The catch of `connect` logs `{ error: String(error) }` and then rethrows the original value; reads the thrown value with `String(...)`, unguarded. A thrown value whose read throws (a revoked Proxy: `String()` throws on it; an Error whose `message` getter throws, since `Error.prototype.toString` reads it) makes the catch itself throw, so `connect` rejects with a TypeError and nothing is logged, where an ordinary Error is logged and rethrown as is. The fix is the house guard placed in the catch: read the value inside its own `try` and fall back to the constant `'unreadable thrown value'` when the read throws. The text of every value that can be read is unchanged.
