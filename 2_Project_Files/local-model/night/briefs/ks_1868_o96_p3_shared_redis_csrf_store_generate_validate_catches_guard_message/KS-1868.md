## What is wrong (one paragraph)

The catches of `RedisCSRFStore.generate` (a failed write; it rethrows the original value) and `RedisCSRFStore.validate` (a failed read; it answers `false`) log `{ error: String(error) }`; reads the thrown value with `String(...)`, unguarded. A thrown value whose read throws (a revoked Proxy: `String()` throws on it; an Error whose `message` getter throws, since `Error.prototype.toString` reads it) makes the catch itself throw, so the call rejects with a TypeError, where an ordinary Error gives the original value (generate) or `false` (validate). The fix is the house guard placed in the catch: read the value inside its own `try` and fall back to the constant `'unreadable thrown value'` when the read throws. The text of every value that can be read is unchanged.
