## What is wrong (one paragraph)

`index.ts` prints its startup banner from the raw environment variable: `API target: ${process.env.SECUURA_API_URL || 'https://demo-pk.secuura.net'}` (`:26`). `verify.ts` computes the real base once (`SECUURA_API_URL`, trailing slashes stripped, default included) and builds every request URL from it, so with `SECUURA_API_URL=https://host/base//` the bot calls `https://host/base/api/...` while the banner prints `https://host/base//`. Kam's ruling (Wednesday, 2026-10-19 01:0x, option a): export the constant from `verify.ts` (part 1, `ks_1624_p1`, which adds the `export` keyword) and print THAT value; do not recompute it in `index.ts`. This part imports the constant and prints it. The `webhook` import, the port, the other two `console.log` lines and `app.listen` stay as they are.
