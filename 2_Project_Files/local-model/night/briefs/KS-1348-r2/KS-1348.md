## What is wrong (one paragraph)

Under `NODE_ENV=production`, `utils/logger.ts:43`-`:48` adds two winston File transports (`logs/error.log`, `logs/combined.log`) with NO `format`, and the logger-level format (`:53`-`:56`) renders nothing, so every line in both files is the literal text `undefined`. Giving the files `json()` alone (#1302) makes them persist EVERY metadata field, secrets included, nested ones too. The ruled rule:
- a logger-level format, placed LAST in the logger-level `combine(...)` so it runs before every transport (the Console and both files), replaces the VALUE of any key whose name ENDS with a secret or PII word (password, passwd, secret, token, apikey, api_key, api-key, authorization, cookie, ssn, email, creditcard, phonenumber; case-insensitive; the packages/shared logger list is covered by these endings) with `[REDACTED]`, recursively through nested objects and arrays;
- it COPIES, never mutates the caller's objects; `level` and `message` are never redacted; an Error, a Date or a Buffer value is passed through as is;
- THEN each File transport gets `format: combine(json())`, the format the production Console already has;
- the message text and the `error` text still reach the files: that is what fail500 exists to log.
