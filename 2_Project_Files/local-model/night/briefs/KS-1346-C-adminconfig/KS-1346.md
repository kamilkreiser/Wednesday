## What is wrong (one paragraph)

`fail500` (`:103`-`:106`) logs a thrown value with `err instanceof Error ? err.message : String(err)`, so a thrown plain object reaches the log as `[object Object]`. The ruled rule, the same line parts A and B carry:
- an Error logs its message (unchanged);
- a string logs itself (unchanged);
- an object logs `thrown <ConstructorName> with fields [<key>, <key>]`, and anything else logs `thrown <typeof>`.
Keys only, never values. This file indents with TWO spaces.
