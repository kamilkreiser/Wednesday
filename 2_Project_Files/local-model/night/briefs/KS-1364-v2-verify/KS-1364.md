## What is wrong (one paragraph)

The registration for `POST /api/v2/verification/verify` (`originate.openapi.ts:2026`-`:2077`) declares its request body as a multi-line `body: {` block (`:2055`-`:2059`) whose only key is `content:`, with no `required`, so the published spec says the body is OPTIONAL. The handler says otherwise: `routes/verificationV2.ts:427`-`:428` (`verificationV2Router.post('/verify', ...)`) reads `documentId, hash, providedHash, contentHash, documentHash, documentData` from `req.body || {}` (`:450`), resolves the hash as `hash || providedHash || contentHash || documentHash` (`:451`), and when there is no documentId, no hash and no documentData answers 400 "Provide a content hash (or documentData to hash), or a documentId." (`:452`-`:456`). The service mounts `express.json()` (`index.ts:103`) on express 4, which leaves `req.body` as `{}` when no body is sent, so an absent body reaches `:452` and is refused with 400. const V2 = '/api/v2/verification/verify';

  return doc.paths?.[path]?.[method];
}

function bodyRef(path: string): string | undefined {
  return operation(path, 'post')?.requestBody?.content?.['application/json']?.schema?.$ref;
}
