## What is wrong (one paragraph)

The lookup catch of `resolvePublicAddresses` reads the thrown value's `message` with no guard. A thrown value whose read throws (a revoked Proxy: any property read and `instanceof` throw on it; an Error whose `message` getter throws) makes the catch itself throw, so the call REJECTS where an ordinary lookup failure returns the refusal `{ ok: false, error }` (the guard still refuses: it fails closed, but with an exception instead of its documented return). The fix is the house guard placed in the catch: read the value inside its own `try` and fall back to the constant `'unreadable thrown value'` when the read throws. The text of every value that can be read is unchanged.
