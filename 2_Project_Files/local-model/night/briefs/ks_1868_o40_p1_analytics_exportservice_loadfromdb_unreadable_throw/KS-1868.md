## What is wrong (one paragraph)

In `exportService.ts` the catch block of `ExportService.loadFromDb` (line 295) logs `logger.warn('ExportService.loadFromDb failed — starting with empty store', { error: err instanceof Error ? err.message : String(err) })` (the read is on line 297). If the query rejects with a revoked Proxy, `err instanceof Error` itself throws a TypeError inside the catch block; if it rejects with an Error whose `message` getter throws, `err.message` throws. Either way the catch throws before the WARN is emitted: `loadFromDb()` rejects (the caller in `index.ts` runs it inside a startup `Promise.all` with the other loaders) and the operator sees no WARN. The fix reads the thrown value inside its own inner `try` into a local `reason`, falling back to the constant `unreadable thrown value`, and the WARN uses `reason`. Nothing else changes: an ordinary Error still logs `{ error: <its message> }` and the log text is unchanged.
