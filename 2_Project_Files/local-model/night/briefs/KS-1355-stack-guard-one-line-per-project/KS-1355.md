## What is wrong (one paragraph)

`list_other_stacks` (`:104`-`:110`) reads one `project|owner|branch` row per labelled CONTAINER from `docker ps` and de-duplicates with `sort -u` (`:109`), which KS-691 added so a 33-container foreign stack prints one line, not 33. But it de-duplicates the whole TUPLE, so when one container of a stack was started outside `start-secuura.sh` (a bare `docker compose`, the KS-1011 case) it carries `owner=unknown`, `branch=unknown`, and that project prints TWICE: once under its real owner and once as `owner unknown, branch unknown` — which reads as a second, unowned stack on the host. Measured at the tip with the cells below: 2 lines for one project. The fix groups by PROJECT in `awk`: the first labelled (non-`unknown`) tuple names the project; its `owner=unknown` containers are counted and appended to that line as ` (+N container(s) with owner unknown)`; a project whose containers are ALL `unknown` still prints once as `owner unknown, branch unknown` (nothing to fold it into); the result is sorted by project. The caller's loop (`:210`-`:213`) reads three `|`-separated fields and prints `  <project> — owner <owner>, branch <branch>`, so the count rides on the branch field and the caller is unchanged.
