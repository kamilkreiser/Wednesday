## What is wrong (one paragraph)

`poll()` catches a failure of `blocksLatest` and asks `this.isRateLimited(err)` before it calls `this.handleError(err)`. `isRateLimited` reads `err?.status_code`, `err?.statusCode`, `err?.response?.status` and `err?.message` with no guard, so a thrown value whose read throws (a revoked Proxy; a Proxy whose get trap throws; an Error whose `message` getter throws) makes `isRateLimited` throw inside the catch: `poll()` REJECTS, `handleError` (already guarded by KS-1868, which hands such values to `onError`) is never reached, and `onError` is never called. The fix keeps the existing expression byte for byte (it moves, unchanged, into a new private method `readsAsRateLimited`, so no existing line is re-indented) and makes `isRateLimited` call it inside a `try`, answering `false` when the read throws, so the caller falls to `handleError` exactly as for an ordinary non-429 Error. Every value that can be read returns exactly what it returned before.
