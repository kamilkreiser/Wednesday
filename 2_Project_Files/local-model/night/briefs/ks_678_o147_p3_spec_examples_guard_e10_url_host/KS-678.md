## What is wrong (one paragraph)

Rule E1 of the published-example guard reads email addresses only (it splits on `@`). A URL on any domain passes every one of E1 to E9, so `https://example.secuura.io/resource` (the KS-678 founding defect: a domain that does not resolve and that nobody is known to own) would be published again without a finding. The ticket asks for a rule that parses a URL-valued example and requires its host to be in a reserved set, or an allowlist entry with a reason.
