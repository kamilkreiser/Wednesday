## What is wrong (one paragraph)

`prisma-generate.cjs` stages the schema in `<svc>/node_modules/.generate`: `fs.mkdirSync(staging, { recursive: true })` at `:68`, a `copyFileSync` into it, `prisma generate`, then `fs.rmSync(staging, { recursive: true, force: true })` in a `finally`. If `.generate` is a SYMLINK to a directory, `mkdirSync` succeeds (the path resolves to a directory), the schema is copied into the link's TARGET, and the `finally` removes only the link: the target keeps a stray `schema.prisma` (measured at the tip: the run exits 0 and the target holds one entry). If `.generate` is a plain FILE, `mkdirSync` throws EEXIST uncaught: a Node stack trace and exit 1, where every other precondition failure prints `generate: <message>` and exits 2 through `fail()`. The fix `lstat`s the path first (`lstat`, not `stat`, so a link is seen as a link) and calls `fail()` for a symlink or for anything that is not a directory; a missing path (ENOENT) and a real directory (a leftover of an interrupted run, reused and removed as before) are unchanged.
