## What is wrong (one paragraph)

Four DB read catches of `ReferralService` pass `err?.message` straight into the logger's meta object, unguarded. `?.` guards a null or undefined value only: a thrown value whose read throws (a revoked Proxy: the `.message` get throws; an Error whose `message` getter throws) makes the catch THROW, so `getCodeById`, `getUserCodes`, `getReferralsByReferrer` and `getUserRewards` REJECT where an ordinary Error gets a logged failure and the documented fallback (`null` -> `undefined`, or an empty list). The fix is the house guard placed before each logger call: read the message once inside a `try` (`?.` kept), keep `undefined`/`null` as they are, coerce anything else with `String(...)`, fall back to the constant `'unreadable thrown value'` when the read or the coercion throws; then `error: reason` (the second meta field is unchanged). The four hunks are ~12 to ~24 lines apart. The three WRITE catches (lines 68, 85, 99), the by-code read (line 192) and the remaining reads of this file are untouched (see Skipped).
