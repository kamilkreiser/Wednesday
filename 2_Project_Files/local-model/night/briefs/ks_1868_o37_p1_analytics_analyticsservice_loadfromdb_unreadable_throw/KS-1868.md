## What is wrong (one paragraph)

In `analyticsService.ts` the catch block of `AnalyticsService.loadFromDb` (starts at line 566) logs `logger.warn('AnalyticsService.loadFromDb failed — using mock data', { error: err instanceof Error ? err.message : String(err) })` (the `error:` line is 568). If the thrown value is a revoked Proxy, `err instanceof Error` itself throws a TypeError ("Cannot perform 'getPrototypeOf' on a proxy that has been revoked") inside the catch block; if it is an Error whose `message` getter throws, `err.message` throws. Either way the WARN is not logged and `loadFromDb` rejects instead of falling back to the mock data. The fix reads the thrown value inside its own inner `try` into a local `reason`, falling back to the constant `unreadable thrown value`, and the log line uses `reason`. Nothing else changes: an ordinary Error still logs `{ error: <its message> }`, and the message text of the WARN is unchanged.
