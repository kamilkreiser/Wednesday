## What is wrong (one paragraph)

In `src/index.ts` the catch of `revokePriorConnectorKeys` and the savepoint catch inside the rotate transaction of `saveKeyAndRetirePriors` read the thrown value's message in their own `try` (`reason = err instanceof Error ? err.message : String(err);`, constant `unreadable thrown value` when the read throws) and log `{ error: reason }` through `log()`. The guard covers only the READ. If the getter succeeds and returns a hostile NON-string (a revoked Proxy, a null-prototype object, a Symbol), the value is passed on uncoerced and the service's own `log()` (a `JSON.stringify` of the line) can throw while formatting it, INSIDE the catch, outside the guard (carried from QA gate 112 for the sibling guards of this file; NOT measured for these two with the real logger). The fix coerces what was read: `reason = String(err instanceof Error ? err.message : err);` inside the same `try`, so a value that cannot be turned into text throws inside the `try` and the existing `catch` gives the constant.
