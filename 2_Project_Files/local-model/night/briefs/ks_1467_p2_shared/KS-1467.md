## What is wrong (one paragraph)

The shared `AppError` constructor (`packages/shared/src/errors/index.ts:44`), mounted by twelve services, ends with `Object.setPrototypeOf(this, AppError.prototype)`. That line runs in the BASE constructor for every subclass instance, so it resets the instance's prototype to the base class: `new ValidationError(...) instanceof ValidationError` is `false` for every subclass, and `new DocumentNotFoundError(..) instanceof NotFoundError` is `false`. The fix is the standard one: `Object.setPrototypeOf(this, new.target.prototype)`. The handler already reads `details` off any `AppError`, so no response changes here.
