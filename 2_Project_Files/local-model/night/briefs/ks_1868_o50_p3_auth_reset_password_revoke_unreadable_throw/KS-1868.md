## What is wrong (one paragraph)

`POST /reset-password` writes the new password, then calls `revokeAllUserSessions(user.id)` inside a `try` (KS-1692). Its catch block logs `logger.error('Password reset: the session revocation THREW after the password write', { userId: user.id, error: err instanceof Error ? err.message : String(err), })` (the read is on line 880) and then throws a `ServiceUnavailableError` (503 SERVICE_UNAVAILABLE, `Your password WAS reset, but your other sessions could not be ended ...`, reset link NOT used). If the revocation rejects with a revoked Proxy, `err instanceof Error` itself throws a TypeError inside the catch; if it rejects with an Error whose `message` getter throws, `err.message` throws. Either way the catch block throws before the log line and before the 503 is built, so the route's outer catch hands `next(error)` a TypeError and the caller gets a generic 500 INTERNAL_ERROR instead. The fix reads the thrown value inside its own inner `try` into a local `reason`, falling back to the constant `unreadable thrown value`, and the log call uses `error: reason`. The 503 is then thrown as before. An ordinary Error still logs `error: <its message>`.
