## What is wrong (one paragraph)

`Start_Up/start-secuura.sh:711` ends the successful start with `echo -e "    Issuer:  demo@secuura.io / demo123"` and `Blockchain/Dev/scripts/start-local.sh:284` does the same with `echo "    Issuer:  demo@secuura.io  / demo123"`. The banner goes to the terminal and from there into CI logs, background-run logs and pasted reports; the project rule is that a script that prints a password is raised as a Critical defect. The fix prints the mechanism instead of the value: the account name stays and the password text becomes `(password: the published demo default - see CLAUDE.md)`. A comment line `# KS-1413: print the mechanism, not the demo password value.` goes directly above the changed line, with the same indentation as that line. `start-secuura.sh:712` (the Admin line) and `start-local.sh:285` stay as they are.
