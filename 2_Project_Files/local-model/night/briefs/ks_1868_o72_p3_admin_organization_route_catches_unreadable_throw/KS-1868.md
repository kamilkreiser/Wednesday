## What is wrong (one paragraph)

In `routes/admin.ts` the organization CRUD routes each end in `} catch (err) { log('error', '[Orgs] <Create|Update|Delete> failed', { error: (err as Error).message }); res.status(500).json({ success: false, error: { code: 'INTERNAL_ERROR', message: 'Failed to <create|update|delete> organization' } }); }` (lines 1455, 1475, 1514).
