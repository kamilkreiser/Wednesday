## What is wrong (one paragraph)

In `IdentusClient.resolveDID`, the catch computes `errorMessage` inside a `try` as `err instanceof Error ? err.message : String(err)` with the constant `'unreadable thrown value'` on throw. A message READ that returns a non-string passes the guard and is returned as is, so `errorMessage` of the resolution metadata is a Symbol or an object instead of text. The fix is ONE line inside the same `try`: coerce the whole conditional with `String(...)`: `errorMessage = String(err instanceof Error ? err.message : err);`. For every string message and every non-Error value the result is exactly what it was (`String(err)` for a non-Error; the message itself for a string; `undefined`/`null` messages read as the words `undefined`/`null` as `String` would have said for a non-Error); a Symbol message reads as its text `Symbol(...)`; a value `String()` cannot convert lands in the existing constant fallback.
