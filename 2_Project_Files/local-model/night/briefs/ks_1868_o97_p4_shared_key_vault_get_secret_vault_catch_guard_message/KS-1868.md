## What is wrong (one paragraph)

The vault catch of `getSecret` reads the thrown value's `message` with no guard. A thrown value whose read throws (a revoked Proxy: any property read and `instanceof` throw on it; an Error whose `message` getter throws) makes the catch itself throw, so `getSecret` REJECTS and the environment fallback is never tried, where an ordinary failure logs a warning and falls back. The fix is the house guard placed in the catch: read the value inside its own `try` and fall back to the constant `'unreadable thrown value'` when the read throws. The text of every value that can be read is unchanged.
