## What is wrong (one paragraph)

The catches of `POST /api/generate-key` (line 270), `POST /api/rotate-key` (361) and `POST /api/detect-pii` (385) begin with `const message = err instanceof Error ? err.message : String(err);` (lines 271, 362, 386) and then answer 500 `INTERNAL_ERROR` (generate-key and rotate-key: the message only outside production) or 400 `BAD_REQUEST` (detect-pii). For a caught value whose read throws (a revoked Proxy throws on `instanceof`; an Error whose `message` getter throws, throws on `.message`) the read throws first: inside an async Express 4 handler the rejection is not forwarded, the request gets no answer and Node sees an unhandled rejection. The fix: read into the local `message` inside its own try, with the constant `unreadable thrown value` in the catch; the answer for an ordinary Error or a thrown string is unchanged. Priority Low: nothing known throws such a value here (no measurement).
