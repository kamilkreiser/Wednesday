## What is wrong (one paragraph)

In `persona.ts` the catch of the switch handler (line 76) computes `const message = err instanceof Error ? err.message : 'Unknown error'` (line 77) and logs it. If the auth call rejects with a revoked Proxy, `err instanceof Error` itself throws a TypeError inside the catch block; if it rejects with an Error whose `message` getter throws, `err.message` throws. Either way the catch throws before the ERROR line is logged and before the generic 500 is sent: the async handler rejects, no log line is written and the caller gets no JSON 500 from this handler. The fix reads the thrown value inside its own inner `try` into `message`, falling back to the constant `unreadable thrown value`; the log call and the 500 body are unchanged. An ordinary Error still logs `{ error: <its message> }`.
