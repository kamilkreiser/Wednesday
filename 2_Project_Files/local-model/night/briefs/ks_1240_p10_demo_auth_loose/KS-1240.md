## What is wrong (one paragraph)

`authenticatePersona` in `services/demo-service/src/services/authClient.ts` calls `fetch(url, { method: 'POST', headers, body })` against the auth service's login endpoint with no `signal`. An auth service that accepts the connection and never answers holds the caller for as long as the socket lives. The function already has a try/catch that logs and answers `{ success: false, error: message }`. The change adds a constant `AUTH_FETCH_TIMEOUT_MS = 10_000` (with a comment) after the `AUTH_PORT` line and `signal: AbortSignal.timeout(AUTH_FETCH_TIMEOUT_MS),` as the last property of the fetch init. On expiry the fetch rejects and the existing catch answers as it does for an unreachable service.
