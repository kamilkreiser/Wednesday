## What is wrong (one paragraph)

In `services/mcp-server/src/http-server.ts`, nine route handlers end in a `catch` that computes `const message = err instanceof Error ? err.message : String(err);` and answers 500 with that text: eight as `res.status(500).json({ success: false, error: { code: 'INTERNAL_ERROR', message: message } })` and `POST /verify` as `res.status(500).json({ verified: false, error: message })`. So the thrown error's own text (a driver message, a file-system error naming a server path, an internal host:port) reaches the caller. The fix, at each of the nine: keep the `const message = ...` line; log the thrown text server-side with ONE `console.error('[mcp-http] <METHOD> <route> failed:', message);` call (the text is yours to word, it must start with `[mcp-http]`, pass `message`, and sit directly before the response statement, or before the `if (!res.headersSent) {` line for POST /generate-package); and answer the constant: the eight envelopes get `message: 'An unexpected error occurred'` (that exact string), POST /verify gets `{ verified: false, error: 'An unexpected error occurred' }`.
