## What is wrong (one paragraph)

Both OAuth grants in `routes/oauth.ts` create their session with `createSession(user, req.ip, req.get('user-agent'), undefined, 'browser')`, and the stored Redis `Session` (`sess:<id>`) carries `clientType`, ip, user-agent, device, expiry and activity, nothing that says "an OAuth grant minted this". A future deploy-step denylist of OAuth refresh tokens that must be selective (OAuth sessions only, interactive logins untouched) therefore has no enumerable target set. The fix, in three places: add `mintedBy?: 'oauth';` to the `Session` interface; give `createSession` an optional sixth parameter `mintedBy?: 'oauth'` and store it on the session object only when given; pass `'oauth'` as that sixth argument at the two OAuth call sites.
