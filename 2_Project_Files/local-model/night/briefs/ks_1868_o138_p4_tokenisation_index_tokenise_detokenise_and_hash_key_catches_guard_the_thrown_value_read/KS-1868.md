## What is wrong (one paragraph)

The catches of `POST /api/tokenise` (line 80), `POST /api/detokenise` (line 112) and `POST /api/hash-key` (line 400) begin with `const message = err instanceof Error ? err.message : String(err);` (lines 81, 113, 401) and then answer `res.status(400).json({ success: false, error: { code: 'BAD_REQUEST', message: message } })`. For a caught value whose read throws (a revoked Proxy throws on `instanceof`; an Error whose `message` getter throws, throws on `.message`) the read throws first: inside an async Express 4 handler the rejection is not forwarded, the request gets no answer and Node sees an unhandled rejection. The fix: read into the local `message` inside its own try, with the constant `unreadable thrown value` in the catch; the 400 answer for an ordinary Error or a thrown string is unchanged. Priority Low: nothing known throws such a value here (no measurement).
