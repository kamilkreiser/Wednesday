## What is wrong (one paragraph)

`check-package-format.sh` runs under `set -uo pipefail` (`:190`). Its selection loop at `:730` tests each package with `printf '%s\n' "$changed_paths" | grep -q "^systemTest/${p}/"`. `grep -q` exits at its FIRST match. When the pushed path list is bigger than the pipe buffer (64 KiB), `printf` is still writing, gets EPIPE, and `pipefail` turns the pipeline's status into failure; the `if` reads that as "nothing under this package", so the package is never selected, never checked and never counted as skipped. The gate then still prints `0 skipped, 0 failed`. The fix reads the list to EOF: drop `-q` and send grep's output to `/dev/null`. `grep` without `-q` exits 0 on a match and 1 on none, exactly what the `if` needs, and `printf` is never cut off.
