## What is wrong (one paragraph)

`check-akto-container-names.sh:82` flags `docker <verb> -flag ... akto-<role>` where every `-flag` is ONE dash-token, so a flag that takes a separate value word (`-u root`, `-e FOO=1`, `--tail 5`) breaks the chain between the verb and the name and the line passes (exit 0, nothing printed) although it targets slot 1. The fix ADDS one more alternative to the pattern (line 82 stays exactly as it is): the same verb group, then one or more `-flag` tokens each optionally followed by ONE value word (`[^-[:space:]][^[:space:]]*`), then the name. Quoted names with a backtick are not covered by the new alternative (stated gap; the existing alternative still covers the no-value forms).
