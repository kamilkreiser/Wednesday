## What is wrong (one paragraph)

`html_docs_check.mjs:120` guards its main block with ``if (import.meta.url === `file://${process.argv[1]}`) {``. `import.meta.url` is the resolved real path; `process.argv[1]` is the path as spelled on the command line. Invoked through a symlink the two strings differ, the main block never runs, and the process exits 0 printing nothing on every input, broken pages included. Measured at the tip: a page with `A[Start --> B[End]` in a `div.mermaid` gives rc 1 and one finding by the real path, rc 0 and no output through a symlink to the same file. The fix compares real paths: `realpathSync(new URL(import.meta.url)) === realpathSync(process.argv[1])` (`fs` functions accept a file: URL object, so no new import is needed beyond `realpathSync`), guarded by `process.argv[1] &&` because `realpathSync(undefined)` throws when the module is loaded with `node -e` (no argv[1]).
