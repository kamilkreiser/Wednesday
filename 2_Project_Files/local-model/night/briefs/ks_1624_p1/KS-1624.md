## What is wrong (one paragraph)

`verify.ts` computes the trailing-slash-stripped API base once, at `:5`, as a module-private `const SECUURA_API_URL`. `index.ts` cannot reach it, so its startup banner (`API target: ...`) re-reads the raw environment variable (`process.env.SECUURA_API_URL || <default>`) and prints a value that can differ from the one the bot actually calls: with `SECUURA_API_URL=https://host/base//` the bot calls `https://host/base/api/...` but the banner prints `https://host/base//`. Kam's ruling (Wednesday, 2026-10-19 01:0x, option a): EXPORT the computed constant and print that, do not recompute. This part (1 of 2) only adds the `export` keyword; part 2 (`ks_1624_p2`) makes `index.ts` import it and print it. Nothing else in `verify.ts` changes: the expression, the default and `verifyHash` stay byte for byte.
