## What is wrong (one paragraph)

`systemTest/__tests__/manifest_readers_agree.test.sh` runs four driver functions (writer, playwright, performance, schemathesis); each ends `2>/dev/null | tail -1`. A driver that fails to start prints nothing, `case_` then reports `FAIL ... writer='' ...` as if the readers disagreed, and the reason is gone (KS-1884: one pre-push failure whose cause could not be measured). The fix sends each driver's stderr to its own file in a private temp dir (`$ERR_DIR/<driver>`, replaced on every call so it always belongs to the current case) and `case_` prints each non-empty one under its FAIL line. The stdout handling, the answers and the exit status are unchanged.
