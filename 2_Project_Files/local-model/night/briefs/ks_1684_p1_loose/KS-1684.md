## What is wrong (one paragraph)

`revoke()` in `services/vc-issuer/src/repositories/credentialRepo.ts` reads the row with `getById(id)` (from the database when it is available), builds the revoked copy and calls `memoryStore.set(credential.id, revokedCredential)` (`:458`). It never writes a `memoryOwners` entry. `getRecordById` takes the owner on the memory path from `memoryOwners.get(id) ?? OWNERLESS`, and `mayRead` refuses an owner-less row, so for a row this process did not itself `store()` (one created on another replica) that is then revoked here, the creator is refused with the unknown-id 404 whenever the database is unavailable afterwards. It fails closed: a foreign caller is refused too. The change: read the record with `getRecordById(id)` (credential plus owner), use `record.credential` where `credential` was used, and after the memory write add `if (!memoryOwners.has(credential.id)) memoryOwners.set(credential.id, record.owner);` (the same has-check `store()` uses at `:65`).

## Where

- `src/repositories/credentialRepo.ts:458` - **must change**: directly after `memoryStore.set(credential.id, revokedCredential);` (under the `// Update memory` comment) one line is added: `if (!memoryOwners.has(credential.id)) memoryOwners.set(credential.id, record.owner);`.
