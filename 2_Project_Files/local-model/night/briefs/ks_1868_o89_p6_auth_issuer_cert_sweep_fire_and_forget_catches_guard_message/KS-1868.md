## What is wrong (one paragraph)

Every catch of the sweep builds the logged value INSIDE the logger call's arguments: `error: err instanceof Error ? err.message : String(err)`, with no guard. A thrown value whose read throws (a revoked Proxy: `instanceof` throws; an Error whose `message` getter throws) therefore throws INSIDE the catch; an Error whose `message` is readable but not a string (a null-prototype object, a Symbol) is passed to the logger uncoerced. The fix is the house guard placed before the logger call: `let reason: string; try { reason = String(err instanceof Error ? err.message : err); } catch { reason = 'unreadable thrown value'; }`, then `error: reason`. For the `.catch((err) => logger...(...))` arrows the expression body becomes a block body so the guard can run first.
