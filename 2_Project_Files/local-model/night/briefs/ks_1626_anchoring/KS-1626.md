## What is wrong (one paragraph)

The non-production batch mock in the anchoring service writes `mock_batch_tx_<64 hex>` as a confirmed anchor's transaction hash. The anchoring placeholder test is the prefix regex `/^(tx_sim_|mock_tx_|tx_)/`, which does not match it (`mock_b`, not `mock_t`; and not `tx_`), so the hash passes as a real on-chain transaction (the KS-522 / KS-587 honest-labelling family). The fix at each site is to add `mock_batch_tx_` to the alternation, giving `/^(tx_sim_|mock_tx_|mock_batch_tx_|tx_)/`. The three old prefixes share no leading text with the new one, so the alternation order does not matter; the new alternative is placed after `mock_tx_` and `tx_` stays last. A real Cardano transaction hash is 64 hex digits and can never contain `_`, so the new prefix cannot reject a real hash.
