## What is wrong (one paragraph)

The catch of the `POST /ipfs/pin` handler reads the thrown value (`error instanceof Error ? error.message : String(error)`) with no guard. A thrown value whose read throws (a revoked Proxy: any property read and `instanceof` throw on it; an Error whose `message` getter throws) makes the catch itself throw, so the async handler REJECTS (Express 4 does not catch it: the request gets no reply and an unhandled rejection is raised) where an ordinary failure logs and answers 500 `INTERNAL_ERROR`. The fix is the house guard placed in the catch: read the value inside its own `try` and fall back to the constant `'unreadable thrown value'` when the read throws. The text of every value that can be read is unchanged.
