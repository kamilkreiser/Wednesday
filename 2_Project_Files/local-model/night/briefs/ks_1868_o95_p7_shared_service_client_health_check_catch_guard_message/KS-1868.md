## What is wrong (one paragraph)

The catch of `healthCheck`, a probe whose failure is the result `{ healthy: false, latencyMs, error }`, reads `error instanceof Error ? error.message : 'Unknown error'` into the `error` field; reads the thrown value with no guard. A thrown value whose read throws (a revoked Proxy: `instanceof` throws on it; an Error whose `message` getter throws) makes the catch itself throw, so `healthCheck` REJECTS, where an ordinary Error gives the unhealthy result. The fix is the house guard placed in the catch: read the value inside its own `try` and fall back to the constant `'unreadable thrown value'` when the read throws. The message text of every value that can be read is unchanged.
