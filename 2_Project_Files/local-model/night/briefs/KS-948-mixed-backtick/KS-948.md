## What is wrong (one paragraph)

`check_shared_relink.test.sh:1221` is `unescaped=$(grep -n '^expect "' "${BASH_SOURCE[0]}" | grep '`' | grep -v '\\`' || true)`. The last stage, `grep -v '\\`'`, drops every line that carries ANY escaped backtick, so a case name with an escaped one AND an unescaped one (the unescaped one is command substitution and RUNS — the KS-945 incident that rewrote `package.json`, comment at `:1208`-`:1220`) is never reported. The fix removes the escaped backticks FIRST (`sed 's/\\`//g'`) and then looks for any backtick left (`grep '`'`). 18 of the file's 46 `expect "` call lines carry escaped backticks today and none an unescaped one, so the suite stays green after the change (measured: 106 passed, 0 failed, both sides).
