## What is wrong (one paragraph)

In `routes/admin.ts` the catch of GET `/api/admin/identity/users`, GET `/api/admin/identity/organizations` and PATCH `/api/admin/identity/users/:id/level` reads the thrown value's message in its own `try` (constant `unreadable thrown value` when the read throws), logs `{ error: reason }` and answers a constant 500. The fix wraps the read in `String(...)` inside the same `try`.
