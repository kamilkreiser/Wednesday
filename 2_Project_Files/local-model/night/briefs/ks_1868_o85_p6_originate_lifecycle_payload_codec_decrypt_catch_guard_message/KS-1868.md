## What is wrong (one paragraph)

The one catch of this function logs `{ error: err instanceof Error ? err.message : String(err) }` with the read INSIDE the logger call's arguments, unguarded. A thrown value whose read throws (a revoked Proxy: the `.message` get throws; an Error whose `message` getter throws) therefore throws INSIDE the catch, so `decodeLifecyclePayload` THROWS instead of returning its marker; an Error whose `message` is readable but not a string (a null-prototype object, a Symbol) is handed to the logger uncoerced. The fix is the house guard placed before the logger call: `let reason: string; try { reason = String(err instanceof Error ? err.message : err); } catch { reason = 'unreadable thrown value'; }`, falling back to the constant `'unreadable thrown value'` when the read or the coercion throws; placed before the logger call, then `error: reason`.
