## What is wrong (one paragraph)

`check-stack-safety.sh` keeps `LAUNCHER_EXCEPTIONS`, a list of `path|reason` entries for scripts that run the platform compose without sourcing `stack_env.sh`. The census checks that every launcher is declared, that no exception is stale, and (the `_reasonless` loop) that every entry has a non-empty reason after the `|`. It never checks that an entry names a ticket, although the ruling was "a reason AND a ticket per entry", so the two Akto entries went in with a reason and no ticket: nobody owns retiring them. The fix is data plus one check: put `KS-666` and `KS-687` in those two reasons, and add a loop that fails the gate when any entry's reason holds no `KS-<digit>` or `PS-<digit>` token.
