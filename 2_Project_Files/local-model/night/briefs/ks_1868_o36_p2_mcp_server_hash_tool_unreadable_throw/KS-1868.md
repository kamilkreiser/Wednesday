## What is wrong (one paragraph)

In `hash.ts` the catch block of the `secuura_hash_document` tool handler (starts at line 33) computes `const message = err instanceof Error ? err.message : String(err);` (line 34) and returns it as `{ success: false, error: message }` with `isError: true`. If the thrown value is a revoked Proxy, `err instanceof Error` itself throws a TypeError ("Cannot perform 'getPrototypeOf' on a proxy that has been revoked") inside the catch block; if it is an Error whose `message` getter throws, `err.message` throws. Either way the handler rejects instead of returning its structured isError result. The fix reads the thrown value inside its own inner `try` into `message`, falling back to the constant `unreadable thrown value`. Nothing else changes: an ordinary Error still returns `{ success: false, error: <its message> }` with `isError: true`.
