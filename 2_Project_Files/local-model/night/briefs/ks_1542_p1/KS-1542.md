## What is wrong (one paragraph)

`resolveOriginateForwardTimeoutMs` refuses every bound that is not an integer from 1 to the maximum and names the refused value in its message as `(got <value>)`. The value is printed with `String()` for everything except strings, BigInts and `-0`. `String([1])` is `1`, which is the text of the VALID bound 1; `String([])` is empty; `String({})` is `[object Object]`. So a reader of the message cannot tell a refused array from an accepted number. The fix prints a non-null object as JSON, and falls back to its type tag only when `JSON.stringify` throws (a cycle, a BigInt inside). Reachable only by a future caller today: `index.ts` passes no override.
