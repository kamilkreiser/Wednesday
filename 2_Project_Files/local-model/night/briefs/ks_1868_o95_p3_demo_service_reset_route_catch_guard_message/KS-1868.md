## What is wrong (one paragraph)

The catch of the `POST /reset` handler reads `err instanceof Error ? err.message : 'Unknown error'` into `message`; reads the thrown value with no guard. A thrown value whose read throws (a revoked Proxy: `instanceof` throws on it; an Error whose `message` getter throws) makes the catch itself throw, so the handler REJECTS before it answers (Express 4 does not await a handler, so the request gets no response at all), where an ordinary Error gets the 500 body with `failedStep`. The fix is the house guard placed in the catch: read the value inside its own `try` and fall back to the constant `'unreadable thrown value'` when the read throws. The message text of every value that can be read is unchanged.
