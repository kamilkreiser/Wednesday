## What is wrong (one paragraph)

`app.get('/api/audit-log', ...)` (`index.ts:553-568`) pages the platform audit log with ``SELECT * FROM platform_audit_log ORDER BY created_at DESC LIMIT $1 OFFSET $2``. `created_at` is `TIMESTAMPTZ DEFAULT now()` and several rows written in one transaction share it to the microsecond, so rows with an equal `created_at` have no defined relative order and Postgres does not promise the same order across two separate queries; with `OFFSET` paging, a tie group that straddles a window boundary can be returned twice or not at all. Adding the primary key as the last sort key (`, id DESC`) makes the order total. The query text is a template literal on ONE line: only the words `ORDER BY created_at DESC` become `ORDER BY created_at DESC, id DESC`.
