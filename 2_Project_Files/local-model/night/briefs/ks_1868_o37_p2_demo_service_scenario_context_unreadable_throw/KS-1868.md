## What is wrong (one paragraph)

In `scenario.ts` the catch block of the `GET /scenario/context` handler (starts at line 112) computes `const message = err instanceof Error ? err.message : 'Unknown error';` (line 113), logs it with `logger.error('Failed to get scenario context', { error: message })` and answers a generic 500 `{ success: false, error: { code: 'INTERNAL_ERROR', message: 'Internal server error' } }` (the thrown text is NOT sent to the client). If the thrown value is a revoked Proxy, `err instanceof Error` itself throws a TypeError ("Cannot perform 'getPrototypeOf' on a proxy that has been revoked") inside the catch block; if it is an Error whose `message` getter throws, `err.message` throws. Either way the error is not logged and the generic 500 is not sent; the handler throws out of its catch. The fix reads the thrown value inside its own inner `try` into `message`, falling back to the constant `unreadable thrown value` (the existing `'Unknown error'` branch for non-Errors is kept). Nothing else changes: an ordinary Error still logs `{ error: <its message> }` and the client still gets the same generic 500.
