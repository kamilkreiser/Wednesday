## What is wrong (one paragraph)

The Vault catch of `getSecret` logs a warning with `error instanceof Error ? error.message : String(error)` (the `String(...)` and `.message` reads are the same unguarded read) and then falls back to the environment; reads the thrown value with `String(...)`, unguarded. A thrown value whose read throws (a revoked Proxy: `String()` throws on it; an Error whose `message` getter throws, since `Error.prototype.toString` reads it) makes the catch itself throw, so `getSecret` REJECTS and the environment fallback is never tried, where an ordinary Error logs and falls back. The fix is the house guard placed in the catch: read the value inside its own `try` and fall back to the constant `'unreadable thrown value'` when the read throws. The text of every value that can be read is unchanged.
