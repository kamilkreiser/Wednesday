## What is wrong (one paragraph)

In `webhooks.ts` the replay handler (admin-only, KS-157) reads the stored event with `query(...)` inside a try; its catch logs `logger.error('Replay failed', { eventId, error: error instanceof Error ? error.message : String(error) })` (the read is on line 316) and then answers the constant `res.status(500).json({ success: false, error: { code: 'INTERNAL_ERROR', message: 'Replay failed' } })`. If the database call rejects with a revoked Proxy, `error instanceof Error` itself throws a TypeError inside the catch; if it rejects with an Error whose `message` getter throws, `error.message` throws. Either way the catch throws before the line is logged and before the 500 is sent, so the handler rejects and the request is left unanswered. The fix reads the thrown value inside its own inner `try` into a local `reason`, falling back to the constant `unreadable thrown value`, and the log call uses `reason`. The response stays the constant 500 `Replay failed` in every case: the thrown text is only ever logged, never sent. An ordinary Error still logs `error: <its message>`.
