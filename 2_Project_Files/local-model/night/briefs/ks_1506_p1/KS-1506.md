## What is wrong (one paragraph)

`app.use('/api/admin/audit', auditExportRouter);` (`index.ts:811`) mounts the audit-export router with no authentication middleware in front of it. The router's only route, `GET /export` (`routes/audit-export.ts:96`), starts with `const user = (req as any).user; if (!user) { ... 401 }`, and `req.user` is set only by `authenticateToken` (`middleware/auth.ts:361`), which nothing runs on this path, so the handler answers 401 `UNAUTHORIZED` to every caller, a platform admin with a valid Bearer included. Measured by the new cells at the tip: an admin Bearer gets `401` (A1, A2), and a non-admin gets `401` instead of the handler's `403 FORBIDDEN` (A3). `authenticateToken(true)` verifies the token, rejects a missing or invalid one with the same `401 UNAUTHORIZED`, refuses a connector JWT presented as a Bearer, and sets `req.user`; the handler's admin-role check then does the authorisation as written. The handler's own `fetch` of the security service forwards the caller's `Authorization` header (`audit-export.ts:145-147`), which the new A1 cell reads on the stub.
