## What is wrong (one paragraph)
`Blockchain/Dev/scripts/run-shell-suites.sh` scores each suite by its exit code alone (`if bash "$REPO_ROOT/$rel"; then pass=…` at :224). A suite that cannot run its cells and exits 0 with a `SKIP —` line (the ks949 PostgreSQL suite: `SKIP — no PostgreSQL binaries … 0/26 cells run`) is tallied as **passed**, and the verdict `shell suites: N passed, M failed (of K)` — the line preflight leg 14 prints and Test Evidence blocks quote — reads the same whether that suite ran all its cells or none. Fix (the ticket's own): the runner recognises a skip — a suite that exits 0 AND prints a line matching `^[[:space:]]*SKIP —` is tallied as **skipped**, the verdict carries the ratio `N passed, M failed, S skipped (of K)`, and the skipped suites are named on a `SKIPPED:` line. Policy, recorded beside the tally: a skip does NOT fail the run (rc stays 0 — ruled for the ks949 suite). NOT in this task: `--check-unreached`, the git-env block, KS-1046 (the preflight's own tally), anything else.
