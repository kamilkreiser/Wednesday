## What is wrong (one paragraph)

In `minting.service.ts` the catch block of `loadFromDb` logs `logger.warn('Failed to load NFT certificates from DB — starting empty', { error: err instanceof Error ? err.message : String(err) })` (the read is on line 129) and then it returns nothing (starting with an empty cache). If the database call rejects with a revoked Proxy, `err instanceof Error` itself throws a TypeError inside the catch block; if it rejects with an Error whose `message` getter throws, `err.message` throws. Either way the catch throws before the line is logged and before the normal return, so the function rejects with the hostile value. The fix reads the thrown value inside its own inner `try` into a local `reason`, falling back to the constant `unreadable thrown value`, and the log call uses `reason`. Nothing else changes: an ordinary Error still logs `{ error: <its message> }`.
