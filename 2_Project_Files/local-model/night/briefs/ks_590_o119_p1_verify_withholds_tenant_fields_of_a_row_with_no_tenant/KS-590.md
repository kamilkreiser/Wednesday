## What is wrong (one paragraph)

Verify is reachable without authentication. `isCrossTenantResponse(req, row)` (verification.ts line 456) decides whether the answer's tenant-owned naming (title, issuer, certification.certifiedBy) is withheld by `scopeTenantFields`. Line 458 reads: `  if (!rowTenant) return false; // no tenancy info on the row — nothing to scope by`. So a row with NO tenant id (`_tenantId` and `tenant_id` both absent or null: a legacy row) is never scoped, and an anonymous caller who holds the bytes is answered with that row's title and issuer organisation. A row WITH a tenant id is scoped for every caller that is not of that tenant (line 460: `return !caller || String(rowTenant).toLowerCase() !== caller;`). Kam's ruling on KS-590 (option 1) makes the legacy row follow the same rule as the tenanted one: the row cannot be shown to be the caller's, so the naming is withheld. The fix changes `false` to `true` on line 458 and replaces its comment. Nothing else in the function changes.
