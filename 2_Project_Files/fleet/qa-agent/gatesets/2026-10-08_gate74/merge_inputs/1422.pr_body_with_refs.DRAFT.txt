## What changed

- systemTest/scripts/check-package-format.sh:180 (KS 998) -- the push-label grep.
  Prior behaviour: `grep -qx` read the path as a PATTERN, so a filename carrying a
  regex metacharacter could match the wrong line or none, and "(in this push)" was
  not a literal statement about the push.
- Blockchain/Dev/services/transfer/src/index.ts:412 (KS 1435) -- rejectTransferSchema.
  Prior behaviour: the schema omitted `signature` entirely, so a wrong-typed signature
  passed validation with 200 and the reject still ran.
- Blockchain/Dev/services/originate/src/originate.openapi.ts:1630 (KS 591) -- the
  transfer-custody request. Prior behaviour: newHolderId was published as a bare
  string, so a spec-legal non-uuid was generated, the runtime rejected it, and
  positive_data_acceptance counted the refusal as a failure.
