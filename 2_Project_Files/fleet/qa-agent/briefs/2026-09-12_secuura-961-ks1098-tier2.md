| argv shape | expected in the PRINTED echo at head | expected in the argv handed to spawn |
|---|---|---|
| `-e SECRET_NAME=value` (two-arg) | value masked | byte-identical to base |
| `-e=SECRET_NAME=value` | value masked | byte-identical |
| `-eSECRET_NAME=value` (attached) | value masked | byte-identical |
| `-qe SECRET_NAME=value`, or any cluster ending in `e` | value masked | byte-identical |
| `--env SECRET_NAME=value`, `--env=SECRET_NAME=value` | masked, as at base | byte-identical |

| a value-taking short flag that is NOT env, whose value contains `e` (`-w /home/example`, `-u deploy`, `-l key=secret-ish`, `-v /etc:/etc`) | printed as at base; never parsed as an env assignment | byte-identical |
| a short-flag cluster with `e` NOT in last position (`-eq`, `-ite`) | **you establish** what docker and k6 actually do with it, and whether the echo matches that parse | byte-identical |
| uppercase `-E`, `-Ee`, `-eE` | **you establish** each tool's meaning; a mismatch between the mask and the real parse, in either direction, is a finding | byte-identical |
| secret values containing `=`, spaces, quotes or a newline, and the empty value `NAME=` | masked for secret names, with no suffix of the value leaking | byte-identical |
