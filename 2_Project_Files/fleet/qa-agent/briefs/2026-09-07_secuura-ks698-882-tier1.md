# QA Agent Invocation Brief — Secuura/Blockchain · KS-698 · PR #882 · TIER 1

**TIER 1.** This is an **authentication-adjacent security surface**: a rate limiter that **fails OPEN
on error** (KS-616). The defect is that **one request** can poison a limiter key permanently, and
because the limiter fails open, that key becomes **effectively unlimited** — a bypass reachable in one
request against any key the caller names. A guard whose failure mode is "no limit at all" gets the
full weight.
