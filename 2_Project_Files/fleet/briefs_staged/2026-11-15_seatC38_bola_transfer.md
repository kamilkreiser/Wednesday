## THE CHANGE (the minimum; the ruling is the spec)
**The rule (D1).** A caller may read a transfer or delegation when ANY of: (i) a person (not `isNonUserPrincipal`) whose `userId` `sameId`-matches one of the object's party fields (transfer: `PARTY_FIELDS`, i.e. `currentOwnerId`, `newOwnerId`, `initiatedBy`, `executorId`; delegation: `delegatorId`, `delegateId`); (ii) a person whose `role` satisfies the shared `isPlatformRole` (SYSTEM_ADMIN / SUPER_ADMIN, either casing, ASCII fold; already imported in `routes/delegations.ts:12`, import it in `index.ts` from `@secuura/shared`). Otherwise the route answers ITS OWN 404 bytes (byte-identical to the unknown-id answer), before any other work. No role other than platform admin widens: ORG_ADMIN, ISSUER_ADMIN, ADMIN, OWNER, USER read only as parties. A non-user principal (key/connector) reads nothing it is not a party to (it never is) and gets no admin arm; a token with no user id is not a party and gets the same 404 (do NOT use `requireCaller`: it answers 401/403, different bytes).
