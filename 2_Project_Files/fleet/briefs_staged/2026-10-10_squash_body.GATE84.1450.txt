## What changes

`Blockchain/Dev/scripts/preflight/lockfile-cleanroom.sh` (preflight leg 2) prints `All N standalone lock(s) pass clean-room npm ci.`, where N counts the locks that a `find` over `services packages frontend scripts` reaches. That line reads like a total; it is a surface. The ticket measured 6 of the 36 locks one earlier PR changed as outside it.

`report_surface` runs after that line when the leg was started with no arguments. It runs `report_surface_lines` in a subshell with git's own list of repository-local variables unset (`git rev-parse --local-env-vars`), asks git for the tracked `package-lock.json` files, prints how many of them the leg installed, and lists the paths of the rest. It ends in `return 0` whatever its subshell does, and the leg's exit-code lines are not edited. What the leg installs is not widened: the `find` line is untouched, so the install-widening is a later change.

**Why a second commit.** The first commit printed the wrong count from a linked worktree. git exports `GIT_DIR` to a pre-push hook that runs in a linked worktree, and with `GIT_DIR` set `git rev-parse --show-prefix` prints an empty string at rc 0 while `ls-files` still lists repository-relative paths, so no lock matched the prefix. The pre-push run of the first commit, from a linked worktree, printed `surface: 0 of 45` and listed 45 of 45 paths (line 49 of its push log). In a scratch repo with a real `pre-push` hook and a real `git push`, the first commit printed `3 of 6` from a main checkout and `0 of 6` from a linked worktree; this head prints `3 of 6` from both. The same four pushes with Apple git 2.50.1 first on `PATH` gave the same four lines.

At the base git tracks 45 `package-lock.json` files (`git ls-files` and `git ls-tree` agree) and the `find` reaches 35. **Computed from those two file lists:** if all 35 pass, the new lines read `surface: 35 of 45` and list 10 paths. The pre-push hook's own run of this head, from a linked worktree, printed `surface: 35 of 45`, equal to the computation; the first commit's run printed `0 of 45`.
