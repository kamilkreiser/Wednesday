  * READ: once, from the query, in a useState initializer. State survives React StrictMode's dev double mount; the app renders in StrictMode (main.tsx).
  * STRIP: in a layout effect at mount, BEFORE any request: navigate({pathname, search: ''}, {replace: true}). This is react-router 7.18.5's own replace, so the router's location and the address bar agree.

  * POSTED: only in the JSON body, once per user action.
