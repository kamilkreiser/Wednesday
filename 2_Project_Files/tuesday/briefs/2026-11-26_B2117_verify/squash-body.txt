The footer's first line (company, product and title) is fitted to the lines that fit above
the hash line, as the change report's is, so a long name no longer pushes the manifest hash
line off the page of the policy PDF. A first line that fits is unchanged, byte for byte. A new
test covers a 250-character name with a 200-character company, released and draft.

The change report's existing fitting is exported and reused; the PDF writer is not changed.
The policy DOCX shares the footer text, so its first footer line is clipped the same way.
No content file or release file changes, so this is not a content release and nothing ships
from it.
