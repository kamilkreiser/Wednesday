RD-445 item 2. When the server runs with NODE_ENV=production, the Marketplace
webhook token check no longer honours MARKETPLACE_SKIP_JWT: the bearer token is
verified as if the flag were unset, and an error line is logged when the router
is built and for every webhook request that meets the flag. Outside production
the flag works as before and now also logs one warning line when the router is
built. The flag is kept for development and sandbox runs.

An instance whose NODE_ENV is unset or is not "production" (compared trimmed
and case-insensitively) still skips the check when the flag is on. The new
cells mock the token library: they prove which path the check takes and what
it does with the answer, not a signature check. RD-445 stays open for items 1,
3 and 4. Not deployed.
