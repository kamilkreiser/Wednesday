## What changes

**RD-793: four data-source writes now need an administrator**

- These four routes checked no role:
  - `DELETE /api/data-sources/:id` (delete a source)
  - `POST /api/data-sources/:id/tables` (add a table)
  - `DELETE /api/data-sources/:id/tables/:tableName` (remove a table)
  - `DELETE /api/setup/data-sources/:id` (delete a source in setup)
- On a configured deployment, any signed-in user, a viewer included, could delete a data source or change its table list.
- Each handler now runs the existing administrator check (`requireAdminFor`) as its first statement. This is the same check the add and edit routes next to them already use.
- A signed-in viewer, or any other non-administrator, now gets `403 {"error":"Admin access required"}`. Nothing else in the handler runs, so the source and its tables are untouched.
- What stays the same:
  - An administrator is answered as before.
  - The open window is answered as before: no sign-in configured, or first-run setup unfinished.
  - A request with no session is still refused 401 by the sign-in check, which runs first.
- The role inventory (`docs/role-capabilities.json`) and its page (`docs/ROLE-CAPABILITIES.md`) are regenerated by the tool. Only the four rows change: viewer 403, and the handler gate is now listed.
- The pending list in `backend/services/capabilities.js` now names only the two connection-test routes.
- Two existing tests keep a hand-written count of administrator checks and gated handlers. They move with the four new checks.

**RD-990: the audit rows carry the full path**

- A refusal answered inside a mounted router used to be audited with a path relative to that router (`/` or `/6`). The audit row then did not say which route was refused. This covers the sign-in provisioning router, the feedback item writes and the sustainability config write.
- A new helper, `requestPath`, gives the full path without the query string. Both audit rows use it: the refused-request row and the state-change row.
- A request answered below no router keeps its path exactly as before.
- Each row keeps its six keys.
