A logging library (src/Datasec.Suite.Logging) and its tests
(tests/Datasec.Suite.Logging.Tests, 191 test cells).

The host does not log through this library yet. Until a later change
wires the host to it, the deny-list protects nothing and nothing runs
the log scanner.

The deny-list: one public way to build a logger; every sink sits
behind the list; no setting switches it off. Six classes (token,
session handle, card string, mail content, file name, password) with
34 name stems, as data in one file. A property name is on the list
when, in lower case and without separators, it contains a stem; its
value is replaced by the fixed text [removed:<class>]. Inside one
object or one list, a value that is itself a listed name makes every
other value of that object or list be replaced. A text that holds a
listed name, then an equals sign, a colon or a comma, then more text,
is replaced whole. A value of an unknown kind, or nested deeper than
32 levels, is left out.

Not stopped by the list: a value in the text of a message template,
in the message of an exception, used as a dictionary key, or under a
name that holds no stem with no listed name beside it; a name and its
value as two properties of one event or as two values of one
dictionary; a name and a value joined by anything but the three
separators; a pair whose key member itself has a listed name; a type
named after what it holds; names and values in two parallel lists.

The cost: harmless values are removed too. On 230 sample events with
no secret in them, 108 lose at least one value (223 of 1210 values).
A text that a user chooses and that holds a stem removes the other
values of the same object or list.

The log scanner: reads every file of a folder and its real
sub-folders and reports each known value (as it is, JSON-escaped,
percent-encoded, base64, URL-safe base64) and every string in the
compact form of a JSON Web Token. A scan that read nothing is not
clean; a file it cannot read is a finding; an empty list of known
values is refused. A finding does not repeat the value or the line;
its path is relative to the folder and is withheld when it holds a
known value. A symbolic link is reported and never followed. Not
handled: a named pipe in the folder (the scan waits, then ends with
an error and no result); a value split over two lines; compressed
files; other encodings; base64 at two of three byte offsets.

Packages, pinned exactly and locked by content hash: Serilog [4.4.0]
and Serilog.Sinks.File [7.0.0], each Apache-2.0 by its own metadata.

Two lines added to Datasec.Suite.slnx and two to
Directory.Packages.props. The root README lists are updated later.

Every choice inside this change was made by the build's coordinator
or by the builder; none is a product decision. Not tested: logs of a
real sign-in; the packages against known vulnerabilities (the
restore's own audit is the only check); the scanner on Windows.
Nothing is deployed; nothing was sent.
