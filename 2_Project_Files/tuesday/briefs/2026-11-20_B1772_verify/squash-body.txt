One workflow with four jobs. linux and windows restore in locked mode, build, test and publish the
server host and run the release guard over the published folder; the linux job also builds the
container image and pushes it nowhere. secret-scan runs a pinned, checksum-verified scanner over the
history and the working tree after a planted control. rules runs every planted control of the guard
and of the repository rules, then the rules themselves.

Not in this change, and still open on WP0.3: the bundle tool in the pipeline and a test bundle; the
fingerprint of the real development CA (the deny-list holds comment lines only, and the guard warns
and passes on an empty list); code scanning results. Nothing is deployed or released.
