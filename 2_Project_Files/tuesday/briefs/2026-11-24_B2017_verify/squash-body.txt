The contracts README says which first-run step each service serves and
what a later write must READ first, in HP's own words: IsServiceEnabled
before EnableService (the Test service is off after every reboot, and a
DisableService undo would turn off a service the run did not turn on);
ExportCertificates before ImportCertificate (an import of a certificate
already in the store has no effect, so a RemoveCertificate undo would
remove one that was there); GetTopLevelButtonRecords before
RegisterTopLevelButton (a matching guid overwrites the existing
record). HP also writes that self-signed certificates are "not
recommended/supported" in the OXPd CA certificate store. The adapter
README's limits line now says these descriptions are committed; the
library still makes none of these calls, and nothing in the repository
calls the three services yet.
