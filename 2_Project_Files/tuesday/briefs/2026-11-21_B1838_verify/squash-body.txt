Adds src/Datasec.Suite.Sessions, the session and token broker of the
server (component C6, work package WP1.5), its test project (53 tests)
and two lines of the solution file.

The broker holds and hands out tokens another component obtained. A
session is keyed by device serial, platform and platform session id; one
live session per device. An OXPd 1.x session gets a 32-byte random
handle, of which only the SHA-256 is kept, bound to its device. The
access token is handed out only through one method that compares the
subject the grant states with the session user. Refresh happens only by
calling ITokenRefresher: lazily inside a 5-minute margin and on demand,
one call per session at a time, bounded by 30 seconds on the broker's
TimeProvider; an answer is kept only when it is valid for the same
subject. Every deadline is held on the wall clock and the monotonic
clock. Each live session has one record, encrypted by the secret store,
under sessions/<random id>; it is erased when the session ends, and the
constructor restores records inside a 10-minute restart window.

The broker never decodes, parses or mints a token, has no sign-in flow,
no timer and no logging, and the server does not reference it yet. One
unreadable record in its partition stops it from starting until the
record is moved aside. No package, workflow or build line changes.
Nothing is deployed; nothing was sent.
