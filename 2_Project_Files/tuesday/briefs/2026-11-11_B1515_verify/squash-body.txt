Two source version ids that Unicode treats as canonically equal over A-Z, a-z and the combining
marks U+0300 to U+036F are now one id and the later copy is refused as a duplicate: U+0344 is read
as U+0308 U+0301, a precomposed letter that carries two marks (or one mark and a further mark) as
its letter and marks, and a run of marks is put in canonical order by combining class.

Still different ids: marks of the same class in the other order, compatibility forms (full-width
letters, ligatures) and letters outside A-Z and a-z. The refusal text, issue code and location are
unchanged; the older letter-and-one-mark table is untouched.

The two new tables (114 letters with two marks, 112 combining classes) are generated with the
Python unicodedata module, version 13.0.0, and are held against independent literal lists by new
tests, with controls that stay green.
