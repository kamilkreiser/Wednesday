The unpriced full proposal and the unpriced short form now print the part code
the server sent in front of the description of a line item. The six places are:
the stream cards, the fleet detail cell, the office table, the optional items
and the software rows of the full proposal; the detail cell and the software
table of the short form. The separator is one space and no word is added. A
code that is absent, null, empty, only spaces, or the same text as the
description prints as before. (included) and (credit) stay at the end of the
line. The three option words are unchanged.

The priced documents are unchanged to the byte. Eight captures of the priced
render of the base are committed and compared byte for byte, for the default
render and for priced={true}.

The no-price check reads more. It reads the value of every attribute, each text
node on its own line, and the whole-dollar forms of each figure as whole tokens.
A part code printed in its own place is read as data. The same text printed
anywhere else is still found. There is no list of allowed codes. The
no-new-word check is exact, apart from one named sentence of the short form.

What the check does not read: a figure staff type into a free-text narrative
field; whatever a code holds when it is printed in its own place; and rounded or
regrouped forms of a figure with cents, which the no-new-word check flags
instead. Not built here: the rental documents, which stay priced, and a durable
record of the choice. The ticket stays open on its third clause.
