Deploy guide and test change. One line of DEPLOY.md changes (line 203, the awk check that a restore script is complete) and one test file changes (the Route B completeness test under packages/db/test).

What was wrong: an older-minor script with no restrict line in its header, cut just after a restrict line, the footer block and an unrestrict line planted in a function body or a data row, was accepted, because the key came from the first restrict line anywhere in the file. A script with no restrict line whose last line was an unrestrict line and a space (an empty key) was accepted the same way.

Now the key counts only when the first restrict line comes before any line that is neither a comment nor blank, and only when it is not empty. No prose in DEPLOY.md changes. PCOMP-115 (the typecheck of packages/db/test) is not in this change.

Tests: the Route B file goes from 37 to 54 rows; no row is removed or retitled. It adds scripts the check must refuse (the older-minor planted trio, an empty key, a restrict line after a statement, a one-dash line, a trailing comment after a statement, a two-space indented comment, a connect command, a byte-order mark, a carriage-return-only line) and one it must accept (header lines --x, ---, -- and a tab, and a line of space, tab, space).

Measured by an independent review over 1,032 script cells on three awk engines (mawk 1.3.4, macOS awk 20200816, BusyBox 1.37): the new line never accepts a script that main's line refuses, never errors, the engines agree on every cell, and it accepts every whole and complete real script. gawk was not run.

Limit: the tests do not pin four hand-made shapes. If a later edit made the check line tolerate any of them, every test row would still pass. They are a comment indented by one space or one tab before the first restrict line (the same test also lets a line such as x--y through), and a line holding only a vertical tab, only a form feed or only a no-break space. The check line as it stands refuses each of them, on all three engines. None appears in the three real 16.15 scripts checked. The limit is in the tests, not in the shipped line. A records step tickets all four after this merge.

Landed under the product owner's 2026-11-03 decision to land the change as it is and ticket the four shapes. Pinned to the checked commit ce523783.
