
## Minimal fix shape (its own lane, test-only; not NX-P)

- **Primary, one place, covers rd711 and rd615:** `__tests__/helpers/rd615-slow-audit-flush-preload.js:28` -- write the signal atomically: `fs.writeFileSync(signal + '.tmp', body); fs.renameSync(signal + '.tmp', signal);` (same directory, so the rename is atomic; the probe's negative control is exactly this). Note rd711's header records the product owner's 2026-11-16 answer to use the preload "unchanged", so this edit is a design touch to that decision -- route it.
- **Alternative, test-side only, if the preload must stay unchanged:** `rd711-audit-flush-serialised.test.js:68-69` (and `rd615...test.js:87-88`) -- make the wait condition "exists AND parses" (try `JSON.parse(readFileSync)` inside the poll, treat a throw as not-yet), so an empty read waits another tick instead of throwing.
- Either change should carry a control that would have caught it (e.g. a cell that reads the signal under a stalled writer, or the probe's plain-vs-atomic pair).
