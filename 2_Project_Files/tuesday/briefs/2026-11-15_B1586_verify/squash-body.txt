report with the page each one starts on. Each row is a link to its section, and the running
header on every page after the cover is a link back to the contents page. The bookmarks are
kept, with the same titles. The readiness report is unchanged: its builder passes no heading,
so it has no contents page and no link. No library change: the links are written by the
PdfPig 0.1.16 already in use, each with a zero border, so nothing is drawn around a link on
screen or on paper.

The contents page is page 2, so every section page moves down by one. The three executive
golden outlines differ from before only by one more page and every section page plus one.
The heading is a string of the report model (null means no contents page), so the Demo copy's
name check counts it as one of the report's own words; a test pins that a customer named
"Contents ..." is not refused because of the heading, with a control that fires.
