The plant check of the Q-03/Q-04 scan test now exercises each alternative of
the pattern whose second fragment holds the generic alternatives, through a
new optional morePlants argument of the pattern factory (default empty, so
every other pattern behaves as before). The fragment check covers the new
plants too, and none of them spells a scanned name whole.

Before this change, dropping either generic alternative from that pattern left
the whole test green; with it, each turns the test red, and dropping the
distinctive alternative still does. The test count and names are unchanged.

One test file changes. No content file, release file, product code or other
test changes, so this is not a content release and nothing ships from it.
