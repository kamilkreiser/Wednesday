The OXPd 1.x client gains Oxpd1Echo: the Test service's two string
echoes, SyncEchoString and AsyncEchoString (a closed catalogue of two
rows read back from the committed binding), sent through one new
internal send with HTTP Basic for the user guest, never admin. A call
takes a message of 1 to 8192 characters, a delay of 0 to 60000 ms and,
for the async echo, an absolute http or https callback address with no
@ and at most 256 characters. A sync answer is read only as one
text-only result alone in the response (ReadTextAnswer); the landed
ReadAnswer is unchanged. CallbackMessage reads a callback body with the
client's strict parser.

The lab gains oxpd1 echo: one echo per run, --pin required, the guest
value read from the credentials file. A --password-name holding ADMIN is
a usage error (exit 2) and a credentials file in which any name holds
ADMIN is refused before any folder or connection (exit 12; names only
are read). An async echo listens first on plain HTTP/1.1 (127.0.0.1
unless --callback-bind gives another IPv4 address), sends the device the
run's own random path, and passes only on a POST there holding the
message (exit 13 when none arrives in time); the listener reads at most
16 requests, each within 5 s, a 16 KiB head and a 64 KiB body. It
writes nothing to a device and owes no undo.
