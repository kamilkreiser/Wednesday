OXPd screen designs, version 1

A modern design for every screen of the sign-in hub, OneDrive, SharePoint, Teams, Mailflow and Universal Print, restyled in the look of the Security Services playbook. What each screen does is unchanged: only the look is new. Approve or amend per page.

What this is

52 screens, one per page. Each page shows the mock at the panel's real size, the functions it keeps (with the analysis line that lists them), the panel limit that shaped it, and one line on what changed from today. Mocks only: nothing is built or changed in the project.

Style source

HP Cyber Security Services Playbook v2.1 (Layout Alignment), cross-checked with v2.0: palette, type scale, radii, buttons, chips, pills, cards, notices, white sidebar. Used as a style only. Every token is traced to its CSS line in STYLE.md. No HP or Workpath branding; synthetic users (Alex Test) and generic product names.

Panel size used: 800 x 600

MEASURED on the HP M577 (FutureSmart 5.10.0.7): its OXPd panel capture is an 800 x 600 PNG (OXPd_2 B2068 STATUS line 87). 02 section 4 gives the browser limits (no SVG, small memory, 10 s script cap, AppleWebKit on OXPd 1.x) but no pixel size. The printer's own Home/Back bar is drawn at the bottom; its height on the M577 is UNMEASURED.
