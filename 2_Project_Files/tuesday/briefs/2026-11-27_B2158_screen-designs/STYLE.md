## 3. How the system is translated for the printer panel (what had to change, and why)

The M577 is an OXPd 1.x printer (FutureSmart 5.10.0.7, measured: `OXPd_2/1_Project_Definition/Briefs/2026-11-24_B2068_STATUS.md:139`). Its panel browser limits come from `OXPd_2/1_Project_Definition/Design/02_architecture.md` section 4, row "Panel UI and browser" (line 257), and the OXPd 1.x reports it cites:

| Playbook feature | Panel limit (source) | Translation on the panel |
|---|---|---|
| Inter, variable weights 680-900 | Fonts: Omni panels have HP Simplified only; Windjammer Arial, Courier New (`Analysis/C1_oxpd1-platform-specs-sdk.md:202`) | No web font is shipped. Mocks use `Arial, Helvetica` as a stand-in for the panel's own face; weights collapse to 400 and 700. Hierarchy is carried by size and colour, not weight steps |
| Line icons drawn as inline SVG (line 632-633) | SVG no (`C1:197`; 02 line 257: "no SVG") | The same icon shapes are to ship as one PNG sprite (HP's advice: sprite maps, `C2:127`). The mocks draw them as plain text glyphs in a tinted square so that no SVG appears in any mock |
| `--shadow: 0 10px 32px rgba(16,50,79,.045)` and modal shadows | Alpha blending and opacity: no (`C1:197`) | Elevation by a solid 1px `--line` border plus a 2px solid bottom edge `#d3e2ec`; no rgba, no opacity |
| Gradients (`.progress>i`, `.hpsc-feature`, brand icon) | AppleWebKit 534 needs the `-webkit-` prefix; alpha not available | Flat fills: progress `#087cbe`, feature band `#0c3552` |
| Grid and flex layouts | AppleWebKit 534+ on FS4 and CE-based FS5 (02 line 257); unprefixed flexbox and CSS grid are later than that engine (general knowledge of WebKit, not measured on the M577) | Mocks use absolute positioning, floats, inline-block and tables only |
| 36px buttons, 30px small buttons, 37px fields | Touch panel; no minimum target size is stated in the project's sources (UNMEASURED) | Design choice: 44px minimum for every touch target, 48-56px for primary actions |
| Desktop sidebar 228px, top bar 68px | 800 x 600 panel (measured, B2068 STATUS line 87); the printer draws its own Home/Back footer on 8-inch panels (`C1:296` "no footer on 4.3 inch or smaller"; seen in the D3 frames) | App bar 56px navy; a 40px strip at the bottom is left to the printer's footer (its height on the M577 is UNMEASURED; about 34px read off the D3 frames) |
| Hover states | No pointer on a touch panel | Dropped; pressed state only |
| Page weight | 2-3 MB of device memory for the whole solution (02 line 257; `C2:132`); small DOM, at most 10-15 list items on small panels (`C2:219`) | Lists page at 8-10 rows on the 8-inch panel; no images except thumbnails served small by the server |
