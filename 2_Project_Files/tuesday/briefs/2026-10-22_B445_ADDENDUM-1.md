Your measurement (PricingPolicy.cs:44-51: any non-null `sections[].rebatePercent` from a caller without Seller+internal-metrics is refused 403 INTERNAL_INPUT_FORBIDDEN) is accepted as the design check's result. A server default is a behaviour change outside your partition and it has a trap: the engine reads an ABSENT rebate as 0, and stored quotes rely on that. A default applied where `rebatePercent` is absent would change EXISTING quotes, which the ruling forbids ("existing quotes are unchanged"). The correct server shape (a default stamped when a section is CREATED, never at calculation) is a separate tier-1 lane that Tuesday will brief after your branch is gated; it is not yours.
