The showcase settings file replaces every app setting of the site on each apply. It did not hold the feedback folder
setting, which was set on the site by hand, so an apply would have removed it. It also let the two sign-in client ids
default to empty, which would blank four sign-in settings, and it moved the budget start date to the month of each
apply.

This change adds the feedback path setting to the file, gives both client id parameters no default and a length of 36,
makes the parameter file stop when either id variable is unset, and pins the budget start date to the existing
budget's start. It adds a committed list of the app setting names and a test that fails when the file's names and the
list differ. The infra README and the hosted configuration section of docs/API.md say what the file does.

Nothing is applied or deployed by this change.
