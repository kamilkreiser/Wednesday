- **D6 WHAT AN ISSUED CERTIFICATE MUST BE** (Q6). `AttachCertificate(id, certificate)` checks, in this order, and the first rule that fails names the reason; nothing is written unless all pass: (1) the id parses (`InvalidArgument`); (2) not empty (`CertificateMalformed`) and at most `MaxCertificateBytes` bytes, default 65536 (`CertificateTooLarge`), both before any parse; (3) the record exists (`NotFound`) and reads (`UnreadableMaterial`); (4) it holds no certificate yet (`CertificateAlreadyAttached`, D9); (5) `X509CertificateLoader.LoadCertificate(certificate)` succeeds AND the loaded certificate's `RawData` equals the input byte for byte, so trailing bytes, PEM text and any second certificate are refused (`CertificateMalformed`); (6) the certificate's public key, as `PublicKey.ExportSubjectPublicKeyInfo()`, equals the stored key's `ExportSubjectPublicKeyInfo()` byte for byte (`CertificateKeyMismatch`); (7) the wall clock of the library's `TimeProvider` lies inside `NotBefore` to `NotAfter`, both compared in UTC (`CertificateNotTimeValid`); (8) the chain of D7 builds (`IssuerNotTrusted`). The chain is built with `X509Chain` and `ChainPolicy.TrustMode = X509ChainTrustMode.CustomRootTrust`, `CustomTrustStore` = exactly the configured issuers, `RevocationMode = X509RevocationMode.NoCheck`, `DisableCertificateDownloads = true` (so no chain build can fetch anything: each member MEASURED present in the reference pack), no `ExtraStore`, `VerificationTime` the `TimeProvider`'s wall clock; the chain must build with every status flag clear. **An empty collection refuses every certificate (`IssuerNotTrusted`).** Why: without an issuer, a certificate with one byte changed in its signature or an extension still carries the right public key and window, and only the issuer's signature catches it (the plan's own test: "a tampered certificate refused"). **Which certificate signs the device certificates is UNMEASURED** (`A3:146` says only that Microsoft is the signer); so, by this default, the product refuses every real certificate until a later lane configures the issuer from a test tenant.
