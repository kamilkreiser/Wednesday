# Lesson ingestion — the async teaching channel

Approved by Kam 2026-08-03. Kam can teach without a session open: any Linear
issue (or comment) he tags with the **`lesson`** label is direct parenting input.

## At every session start (after the Linear check)

1. Query WED issues labelled `lesson` that are not Done.
2. For each: read fully — issue body + comments. This is Kam speaking, possibly
   dictated late at night; read for intent.
3. Classify: correction | preference | contemplation task | guidance.
4. Write the learning file in `learnings/` the same session (template rules:
   provenance = the Linear issue ID, date, verbatim quote where useful).
   Contemplation tasks additionally get genuine written reflection — in the
   learning file or a dedicated note — never a performative acknowledgment.
5. If it's a correction, increment the ledger (`learnings/_ledger.md`) per the
   frequency-weight rules.
6. Close the issue with a comment: what was learned, where it's filed, what will
   change in behaviour. The comment is the receipt that teaching landed.
7. Mention it in the morning briefing / next reply to Kam — one line.

## Notes

- The label also works mid-session: if Kam says "make that a lesson", file it
  AND create the labelled issue already closed, so the paper trail lives in both
  systems.
- When WhatsApp (WED-10/11) and Agent Mail (WED-8) arrive, they become
  additional inlets feeding this same procedure.
