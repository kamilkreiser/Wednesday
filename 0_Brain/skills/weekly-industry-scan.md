# Weekly industry scan — ritual

Commissioned by Kam 2026-08-03: *"a heavy analysis into industry developments and
industry best practices… being up to date with how things are evolving would be
extremely useful. We can then review what to implement."* Cadence: weekly, in a
06:00 slot (day TBC with Kam; pairs naturally with consolidation weekend). Until
the WED-16 scheduler ships, run in the first session after each week rolls over.

## Scope (what "industry" means for us)

1. **Agent engineering:** Claude Code / Claude API capabilities, agent harnesses,
   memory & self-improvement techniques, multi-agent orchestration patterns.
2. **Model landscape:** frontier releases and the challenger approaches (US
   frontier, Chinese efficiency/iteration school, Japanese collective-intelligence
   school), pricing shifts, open-weights movements.
3. **Practice:** what practitioners are actually running in production — coding
   supervision loops, validation patterns, second-brain systems.
4. **Kam's stack specifically:** anything that changes the calculus for Azure,
   GitHub, Linear, WhatsApp bridges, TTS, or the tools his projects sit on.

## Method

- Fan out 2–4 research agents (web) across the scope areas; fresh sources only
  (last ~2 weeks preferred).
- Synthesize into ONE report: `1_Project_Definition/Discovery/research/`
  dated `YYYY-MM-DD_industry-scan.md` — findings ranked by *actionability for
  us*, not by noise level.
- Each actionable finding gets a **proposal**: what to adopt/trial, cost, risk.
  Proposals go to Linear (label `proposal`) for Kam's review — nothing is
  adopted without his call.
- Morning briefing after the scan leads with the top 1–2 items in one spoken
  sentence; detail stays in text.

## Guards

- No FOMO adoption: a finding must beat something we already do, not merely be new.
- Date-stamp everything; the scan is episodic memory, proposals are the output.
