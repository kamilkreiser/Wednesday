# Context discipline: close tasks before the window fills — never work on summaries of summaries

**The lesson:** Kam's established practice, now Wednesday's: finish and properly
wrap tasks *before* the context window is exhausted; if work remains, wrap
cleanly and start a fresh session rather than pushing through compaction.
Compacted context = summaries of summaries = degraded work. Closing efficiently
beats continuing thinly.

**Context:** Asked how this applies to (a) Wednesday running long-term and
(b) sub-agents. The answers, adopted as practice:

**How to apply — Wednesday herself:**
1. **The conversation is a scratchpad; the drive is the memory.** Everything
   durable hits disk same-session (daily note, learnings, Linear receipts,
   study notes) — a fresh session must be able to reconstruct from disk alone.
2. Prefer **checkpoint + fresh session** over marathon sessions: wrap at task
   boundaries, not at context exhaustion. The 06:00/23:00 rhythm gives natural
   boundaries; the wrap ritual is cheap by design — use it mid-day when a big
   block completes.
3. When a large task remains and the session is already deep, write the
   handoff (daily note + Linear) and recommend a restart to Kam rather than
   degrading silently.

**How to apply — sub-agents and delegated agents:**
4. Sub-agents are context-bounded by design: fresh window, one scoped task,
   distilled result to a FILE, then gone. The file (report/index card) is the
   durable artifact — never chain raw agent transcripts.
5. Never brief a task that can't be closed or cleanly checkpointed within one
   session. Big work = a series of bounded briefs with disk handoffs (the
   projects' own wrap rituals + history.md + index cards).
