# BLUF — the human's reading time is the scarce resource

**The rule:** every ticket comment, status update, sign-off request and written
update — mine and every agent's — is structured:

**## BLUF** — the shortest logical summary. What is true now, what changed, what
it means. A reader who stops here must be correctly informed and not misled.
Not a teaser: no "see below", no suspense.

**## Recommendation** — what I propose, or the one thing I need from the reader.
If nothing is needed, say "No action needed" explicitly.

**## Detail** — evidence, commits, matrices, caveats, reasoning, alternatives.

**What prompted it:** Kam learned that Peter reads *every* ticket personally,
and it takes him a long time. We write long because we are thorough — which is
right — but burying the conclusion under the thoroughness taxes exactly the
person whose review we most want to keep.

**The deeper principle, and why this is not a formatting preference:** Kam's
framing was *"it is good to keep a human in the loop. we should make it as easy
for them as possible."* A human gate only works if the humans can keep standing
at it. Every unit of avoidable reading is a small withdrawal from their
willingness to stay in the loop — and the loop is the safety property. Peter
argued for exactly this on KS-480 the same week, from the other side.

**How to apply:**
1. Write the Detail first if that is how the thinking goes, then write the BLUF
   last — and be ruthless about length. The BLUF is the hardest part.
2. **Never put a decision request only in the Detail.** If something is needed,
   it belongs in Recommendation.
3. **Never write a BLUF you would have to walk back** after the Detail. If the
   honest answer is "it depends", say so plainly rather than implying a clean
   one.
4. It changes where the conclusion sits — never what gets investigated or how
   rigorously.
5. Same shape applies to how I write to Kam: this is the sibling of
   [[2026-08-06_ask-format-client-project-options-rec]] (Client/Project ·
   problem · options · recommendation) — both exist so the reader spends their
   attention deciding rather than reconstructing.
