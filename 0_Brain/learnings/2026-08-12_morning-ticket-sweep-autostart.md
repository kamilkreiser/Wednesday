# Morning ritual: sweep every project's tickets, start the agents unprompted

**The grant (recorded per go-slow rule 5):** the morning session checks each
active project's board for outstanding tickets/tasks and, where any exist,
launches that project's agent and briefs it to start — **without waiting for a
per-morning confirmation from Kam.** This relaxes the "propose priorities and
wait" morning step for ticket-outstanding work; it is the autostart version of
the 08-07/v1.3 execution scope.

**Scope:**
1. **In:** Secuura/Blockchain · Datasec/NexusAI · Datasec/Vision (portal +
   QuickQuote). **Out for now:** myPKI, CypherKey, Lead_Bot (Kam's explicit
   skip; revisit only when he says so).
2. **Unchanged boundaries:** v1.3 signature classes (prod, money, external
   comms to humans, irreversible actions) still pause for Kam. Briefs still go
   through `send_brief.sh` with provenance. Scoring/verification duties
   unchanged.
3. **Sweep before briefing** (the 2026-08-11 KS-584 sequencing rule): the
   board read — including client-human responses (Stuart, Peter) and tickets
   NEW since the last session — happens before any brief is written, so the
   brief carries the whole board's context, not the previous day's plan.
4. Morning report to Kam becomes a receipt ("swept X/Y/Z, started A and B on
   these items"), not a request.

**Why (context):** day one of this grant followed the coordinator/QA model's
first full day — Kam is extending autonomy along the axis that just proved
itself (board breadth + delegation), consistent with autonomy-is-earned.

**Enforcement:** encoded into `Launch_Wednesday.command` boot prompt step 10
the same hour it was granted (a promise is not a mechanism).
