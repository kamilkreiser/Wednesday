# Correction ledger — LAPTOP (Datasec) seat

**Why this file exists (structural, and it is itself a finding).** From 2026-09-07 two Wednesday
seats run concurrently: the Studio owns Secuura, this laptop owns Datasec. The laptop handover
correctly forbids writing the shared files — `NEXT-PICKUP.md`, the daily note and **`_ledger.md`** —
because they are the Studio seat's that session and both drives sync. But **the split gave the
Datasec seat nowhere to record a correction**, and learning capture is a same-session duty, not an
optional one. A row written nowhere does not fire at the next boot.

So: this seat's rows live here, in the same format, and **merge into `_ledger.md` at the next
consolidation** when only one seat is live. Nothing here is deleted; the merge is a move.
**Raise at the weekly consolidation:** the two-seat design needs a named owner for every shared
artefact, or a per-seat file for each — decided once, not re-improvised per session.
