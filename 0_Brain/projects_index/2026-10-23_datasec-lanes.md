## HOW

1. `date` first. Open set = every issue whose status is not Done in the two Jira dumps (`HPSMPOC.json`: 325 issues, 122 open; `MPSCALC.json`: 316 issues, 302 open), minus the exclusion labels. The dumps carry summary and labels only, so descriptions and the last two comments of every candidate were read with a Jira GET of `/rest/api/3/issue/<key>` inside a Python process using the project's own `.env` (credentials never printed; every call a GET; no JQL beyond what the dump already held). HPSM-POC: about 40 descriptions read in full (the ones not excluded by title or label); MPS: 128 descriptions read (every non-spec-seed ticket not matched by a commit subject) and key paths extracted by regex then checked against the tree; Composer: BACKLOG.md rows parsed by state word (358 rows, 99 not DONE/CLOSED/DEPLOYED/MERGED/FIXED...), 9 read in full.
2. Repo state at main by `gh api -X GET` with each project's own `GH_CONFIG_DIR` (recursive git tree, commit list, open pull requests, raw file contents for a dozen line cites). No git verb touched a repo; no fetch, worktree or checkout. `git -C ... ls-remote` was used once per project to confirm the heads.
3. "Already on main" for MPS is a heuristic: digits in the prefix of any main commit message that names MPSCALC. It over-matches (a bare number in a subject) and under-matches (multi-ticket commits that name none). It was used only to move a ticket OUT of the lanes, never into one, and the lane tickets were then re-checked by hand against their descriptions.
4. Lanes were formed by file family, then made pairwise disjoint: the generator compares every pair by exact path, directory prefix and glob, prints the result, and was run until it printed 0. Tickets that touch a single-writer file (docs/API.md, openapi.json, Dtos.cs, the generated client, styles.css) were put in one owner lane or made serial rather than split.
5. Routing: P1-P4 first, then the table. Sonnet for C2 builds and tests (rows C2, G2); Opus where the task is a security/money design surface (C3) with a G1 Opus gate on tier-1 surfaces. Tests-only lanes get the G2 Sonnet gate. No local model: P4.
