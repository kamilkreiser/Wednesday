HPSM-POC: what HP will see on Tuesday

Reading copy for Kam, before HP's review on Tue 13 Oct 2026. Drafted 11 Oct 2026 for Friday. Datasec / HPSM-POC only.

All data shown is synthetic. Every customer, figure and screenshot in this pack is made-up sample data from the demo seed or test fixtures. No HP data and no real customer data.

What changed for Tuesday

  • Industry on customers. A customer can now carry an industry, picked from a list (for example "Healthcare (HIPAA)"). Display only: it changes no score. Beside it on Home, a greyed-out "Your tools (coming later)" placeholder that does nothing yet.
  • Device identifiers dropped at import. When a device file is imported, serial number, IP address, MAC address, host name and location are no longer kept. Firmware, model and the counts are kept.
  • "Preview: next phase" attribution page. A new, clearly labelled page showing how activity could be attributed in the next phase. It runs on synthetic sample data, marked SAMPLE. Customers appear only as ORG-nnnnn aliases; staff and printer numbers only as ranges.
  • Aliases on the Automation metrics dashboard. The Customer column now shows ORG-nnnnn instead of the customer's name, and the linked per-customer metrics page shows the alias to Demo callers.
