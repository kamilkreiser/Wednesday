**3. The holder update, before and after; what a "refused" change returns.**

- **Control:** the ISSUER's own later event still replaces them (I5).
- **There is no refusal.** `POST /api/anchors` still answers **202** with today's body, which carries no identity. The existing "kept the stored anchor metadata" warning still fires only for a real keep: a refused caller (I6) or a hash or type mismatch.
