===== TICKET =====
KS-1250 — O-2: RUNBOOK §2.2 documents SMOKE_BASE_URL, but scripts/smoke-test.sh ignores it [Backlog]

The runbook (§2.2) tells an operator to point the smoke test at an environment with `SMOKE_BASE_URL`. `scripts/smoke-test.sh` **doesn't read it**, so it runs against its default target whatever the variable says.

The risk is a smoke run that looks like it checked kintsugi or demo when it actually checked something else. Found by the #1037 gate.

## What to do

Make the script honour `SMOKE_BASE_URL` (and print the target it's using), or correct the runbook.
