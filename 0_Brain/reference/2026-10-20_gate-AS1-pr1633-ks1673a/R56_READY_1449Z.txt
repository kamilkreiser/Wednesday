## CAUSE

Nothing in m365 bound a connection to its organisation. `GET /api/sites` returned every site together with its `connectionId`. That id then opened `GET /api/onedrive/files` and `POST /api/onedrive/files/:id/sync` with **the owning organisation's own Microsoft token**. `init` took the org from the body.

## FIX

The org comes from the token: `req.user.organizationId`, set by shared `authenticate`.

**7 helpers:**
- `callerOrg` — returns `null` for absent, non-string or whitespace values
- `requireCallerOrg` — 403
- `ownedBy` — both values non-empty and equal
- `ownedConnection` — reads the DB first, unchanged
- `ownedMemConnection` — the warm map, unchanged
- `orgOwnsConnectionId`
- `ownedSite`

**14 routes are bound, and no route's lookup SOURCE changed.**
- Named-resource routes give the same answer an unknown id gives.
- List and create routes give 403 when the token carries no org.
