Status words: ANSWERED = the site states the answer; PARTLY = the site states part, the missing part is named; NOT ON THE SITE = no article answers it (searched the saved text of all 84 articles for the key words, with positive controls on other words). A quote is copied exactly from the page. Short form `A:<id>` = `https://help.hpauthsuite.com/support/solutions/articles/<id>`; the full URL is given on first use in each row.

Caution on trust: every article is Datasec-support prose, "Modified on" stamps mostly carry no year, and the release notes and known-issues list say November 2026 on the page. The site is a statement by the product team, not a measurement. The site describes the PRODUCT AS SHIPPED (V4.4); our brief's questions ask about the same product, so it is the right text to check against, but nothing here is run evidence.

## 5. Things on the pages worth a look (not asked, but bearing on the build)

- Card emulation (V4.4) lets an admin type a 4 to 6 character card ID, register it in Entra and test sign-in with no reader: a ready-made way to test our card path (A:47001250241).
- Cloud environments (V4.4): Commercial default; GCC, GCC High, DoD and Custom; "We have not Allowed the GCC Options to be configured at the Printers Console" (A:47001250241).
- Token design: auth code + PKCE, offline_access, 90-day refresh token, stored in Custom Security Attributes (A:47001285083). Universal Print has its own device tokens (same article).
- Printers: Workpath only, firmware 5.10.0.7, genuine consumables, "We only support English Language / localization", 4.3in screens supported for Universal Print, Pull and Direct but not Mailflow (A:47001246252, A:47001243208).
- Network: HTTPS 443, UDP 9930, IPP on TCP 631 (A:47001276381). The page names a licence server host and a public IP address; those are service endpoints, not secrets, and are not copied here.
- A Datasec support contact mailbox, a sales mailbox and a licence mailbox appear on pages (contacts, not secrets). One article asks customers to email an App Registration secret value to Datasec ("The New Secret (Value):", A:47001280225): a practice to be aware of, no secret is on the page.
- No passwords or keys were found on any page.
