## Defect found: the format gate silently drops `akto` on a large push (not this PR's)
Every merge-in push logs `check-package-format.sh: line 730: printf: write error: Broken pipe`, and the gate reports 4 packages checked. Five packages have a `format:check` script and all five changed in this push (`akto` 196 files), yet `akto` was never judged. Cause, reproduced: the selection loop runs `printf '%s\n' "$changed_paths" | grep -q "^systemTest/${p}/"` under `set -uo pipefail`. `grep -q` exits on its first match; when the path list is larger than the 64 KiB pipe buffer, `printf` is still writing, gets EPIPE, and pipefail turns the pipeline false, so the package is read as unchanged. This push's list was 1,736 paths / 116,058 bytes.
