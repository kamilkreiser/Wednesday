**m-1 (Minor; a pre-existing design gap the lane carries into ALLOW; documented in docs §11). With the owner's terminal setting on, a `Bash` command that searches or globs a folder holding files on the owner's exclusion list reads them unasked, while the same search through the `Grep`/`Glob` tool is refused.**
- Where: `crates/coagent-policy/src/engine.rs:433-442` (`a.may_read_excluded = true` only when `role.is_recursive()`, i.e. a search tool's `SearchRoot`) and `:1038` (`MayReadExcluded` = that flag); the owner allow at `:953-957` with `is_owner_terminal_command` `:967-969`.

(excl **/.env*)" and "7b Bash cat src/.e* (excl)": `ALLOW "allowed: the owner chose ALLOW for this session"` with `Allowed`; rows "Glob **/* in ws" / "Grep src": refused as "a search that could read files on the owner's exclusion list". Today all four ask (T0/T3).
- Why Minor and not Major: nothing is switched on (dark, §5); the engine's own definition of the class is met exactly (the action does not carry `MayReadExcluded`, so the brief's NO GO line "an action that carries one of the 16 refused classes is allowed" is not hit as the code defines it); naming an excluded file or folder in the text is still denied at [5]; and docs §11 states this case plainly.
