## 7. Kam's ks1346 logging rule
- **No new log line.** The 7 changed lines alter only the VALUE passed as `error:` to existing lines (message, level and keys are unchanged). For a string message the value is unchanged (the pre-existing `err.message` convention). For a non-string message, head logs `String(m)` or the constant, where base passed the whole object to the formatter, which serialises its field VALUES (e.g. production base `{"a":1,"self":"[Circular]"}`). So head logs strictly less of a thrown object's values. **Complies.** One residual is G130-F5.
