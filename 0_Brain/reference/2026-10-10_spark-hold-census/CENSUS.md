## Instrument

1. **Population.** `night/READY_*.md` filename regex `_(\d{4}-\d\d-\d\d)\.diff\.md$`, date >= 2026-10-05, run dir parsed from the `CANONICAL PATCH =` path; done.md rows split on `|`, verdict starts `PASS`, date >= 10-05, run dir basename grepped (`in`) against all 435 `READY_*.md` bodies.
2. **Apply state.** For each section in `out.md.checker/sections.json`: `git apply --cached --check` forward, and with `-R`, against an index read from `origin/develop`. If the section has recorded options (line 2 of `section_N.opts`), the same two checks again with those options (`Fl`/`Rl`). Codes in the table: F/f = forward ok/fail, R/r = reverse ok/fail; `[L:..]` = result with the checker's recorded options.
3. **Develop corroboration.** Added lines (>= 25 chars, containing a 4-letter word) are looked up as stripped lines in the tip's version of the same path (`present a/b`). `git log origin/develop -S<longest present line> --reverse -- <path>` names the introducing commit; for rows with absent lines, the longest absent line goes through the same `-S` (UNRAISED rows: none).
4. **Class rule.** every section reverse-ok (strict or with recorded opts) -> MERGED; else if any section has neither direction and >= 90% of added lines are present on develop -> MERGED-AMENDED; neither direction and < 90% -> STALE; all sections forward-ok strict and no PR-ref hit -> UNRAISED; forward-ok only with recorded opts -> UNRAISED-L; then SUPERSEDED if a later round of the same ticket has the identical file set.
5. **PR refs.** For not-on-develop rows: `git log --remotes=pr --not origin/develop -S<line> -- <path>` for the top-3 longest absent added lines, plus `--diff-filter=A -- <path>` for each section path (catches the new test file), then `for-each-ref --contains` to name the `pr/N` refs. PR state (open/closed/merged) is UNMEASURED: no GitHub API was used.
6. **Partition.** Live-seat file lists from `git diff --name-status origin/develop...pr/1448` and `...pr/1450`; pairwise: `git apply --cached A` then `--check B` for each UNRAISED pair sharing a path, `read-tree origin/develop` to reset after each (index clean at the end: `diff-index --cached` empty).
