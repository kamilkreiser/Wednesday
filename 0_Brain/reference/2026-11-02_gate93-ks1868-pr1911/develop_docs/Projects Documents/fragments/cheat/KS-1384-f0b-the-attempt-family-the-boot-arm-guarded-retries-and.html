KS-1384 F0b: the attempt family, the boot arm, guarded retries and waits outside the lock

What to know.A refused anchor is retried only when every attempt of the same payload re-polls absent; all attempts spend one family outpoint, so at most one can land. A family with no outpoint never builds a second attempt while one may still land (gate 48, round 2).
For about 2 h after each anchoring restart the old “already been included” rule still rests the row (the boot arm). One anchoring process per wallet; no container overlap at recreate.
With nothing to spend an anchor waits, outside the wallet lock, for up to 2 h, then fails once. F0 means MORE transactions land: a refused event is retried, one more fee per refused event.
Not measured here.A real chain or Blockfrost, replica lag, the wallet census, the four platform suites, a running stack, Node 24 (LTS), any box.
