USER :root (no user part) is still read as non-root: nothing has measured that it runs as root.
Measured gap: ../node_modules/… now passes too, and absolute wrong places already did; the guard does not check where the link lands.
Gotcha when you run this locally. Under core.filemode=false, git apply leaves the guard and its suite 0644 on disk while the index keeps 100755. Run them with bash, or chmod 755 both.
