Offline evidence only: base 21 failed | 6 passed (27) → 27 passed, service suite 845 passed. A live run is owed and the ticket does not move to Done.
Gotcha. The six cells that pass at the base too are the 200-path controls. If a future change makes all 27 pass at the base, the suites have stopped discriminating — check the red arm before trusting the green one.
