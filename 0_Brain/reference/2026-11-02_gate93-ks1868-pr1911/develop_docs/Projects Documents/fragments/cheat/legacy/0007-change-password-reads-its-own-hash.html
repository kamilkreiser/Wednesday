change-password reads its own hash — KS-1005

What to know.POST /api/users/me/change-password returned 404 for every password account: the row was loaded with getUserById, whose column list omits password_hash, so !user.passwordHash threw NotFoundError before the password was ever checked.
It could not tell a correct current password from a wrong one — both 404.
Now loaded with getUserByIdWithPasswordHash.
A passwordless (social / wallet) account still answers 404, by ruling.
