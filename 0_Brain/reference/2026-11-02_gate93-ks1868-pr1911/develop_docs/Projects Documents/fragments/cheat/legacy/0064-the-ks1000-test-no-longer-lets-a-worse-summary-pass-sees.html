The ks1000 test no longer lets a worse summary pass, sees nested brackets, and pins the expectRun call sites — KS-1765

What to know. Three residuals KS-1529 left in services/auth’s ks1000-auth-test-files-are-type-checked-against-a-shrinking-baseline.test.ts are closed, all in that one test file. expectRun’s string predicate is a substring match, so the old green summary 0 new; 0 stale baseline entries was contained in 10 new; 0 stale baseline entries: AUTH_GREEN_SUMMARY is now a RegExp with a lookbehind that refuses a digit directly before 0 new.
The guard that keeps a cell from comparing a checker run as one value now counts bracket depth, so [parts[0], r.status, r.out] is caught, and steps over quoted strings and template literals so a '[' inside the value cannot make it read on into the next statement. Two new cells pin every ordinary expectRun call (a numeric status and a predicate that can fail: not '', not /./) and a floor of 30 ordinary calls.
Adding an expectRun call is fine: the floor is a floor. Deleting one, or replacing it with a bare status check, goes red; lower ORDINARY_CALLS_FLOOR in the same commit only if the deletion is intended. Calls inside expect(() => ...) or thrownBy(() => ...) are the subject of a cell that expects them to throw, and are not counted.
Gotchas when you run this locally. Run the suite with the service directory as the working directory. ks1009 finds the Dev root from process.cwd(); run from the repo root (for example vitest --root from a shell sitting in 2_Project_Files) it fails with could not locate the Dev root, which reads like a regression. npm --prefix Blockchain/Dev run test --workspace=services/auth sets the directory for you.
Under load the default timeouts go red on cells that are not yours. Three ks949 cells (they end at exactly the 5 s default and pass alone, 31 / 31) and the auth.integration hook (10 s, 56 cells skipped) failed at the defaults before and after this change. Pass --testTimeout=120000 --hookTimeout=120000 and the suite is 1188 of 1188. This is the class KS-1155 tracks.
A mutant copy of the ks1000 file under src/__tests__ is type-checked by the ratchet and scanned by the REAL cell. Keep it only while no ratchet check runs and delete it after the run. A copy that reads its own text (SELF) sees the mutant, which is what the guard cells want.
A mutant must parse, and a row must be able to fail. The first form of the escaped-quote row passed with escape handling removed, because the scan still reached the same fields; it only discriminates when a quoted ] follows the escaped quote, so a mis-read string closes the value early.
Not measured here. The four platform suites (Schemathesis, Akto, Playwright, Performance) are UNMEASURED here. Nothing ran on either box. 14 other call sites use a string predicate that starts with a digit and share the substring property; they are named, not changed.
Not proved by the pin: that any predicate is the right one, a predicate swapped for another that can fail, or a removal paired with an addition elsewhere (measured: the cells stay green). Not run on an LTS Node: the host carries only v26.8.1.
