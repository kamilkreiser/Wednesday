An undeclared operation is invisible offline: the contract suites have nothing to generate against it, and a change to its response shape breaks no test.
It is now registered on the shared registry, so npm run generate-openapi emits it. This is narrowing, not closing — one of ~157 routed-but-undocumented operations.
