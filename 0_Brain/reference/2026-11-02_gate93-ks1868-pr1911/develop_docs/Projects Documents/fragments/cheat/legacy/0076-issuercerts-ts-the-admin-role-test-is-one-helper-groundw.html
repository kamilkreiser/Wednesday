issuerCerts.ts: the admin-role test is one helper (groundwork, not the KS-1536 fix) — KS-1536

What to know. The four certificate gates in services/auth/src/routes/issuerCerts.ts (write, read, revoke, sign) each copied the same two-line admin-role test. They now call one exported helper, hasAdminRole, whose body is those two expressions. Behaviour does not change: every spelling admitted or refused before is admitted or refused now.
This is groundwork for the role-vocabulary class and not a fix for KS-1536, which is about seven divergent role lists. A local model wrote the patch; it is applied unchanged. Test cell R3 is a source-text check of the file.
Not measured here. The other six role lists, a running stack, and a Node 24 LTS run (the host is Node 26.8.1).
The four platform suites (Schemathesis, Akto, Playwright, Performance/k6) are not claimed as passing. The change is not deployed.
