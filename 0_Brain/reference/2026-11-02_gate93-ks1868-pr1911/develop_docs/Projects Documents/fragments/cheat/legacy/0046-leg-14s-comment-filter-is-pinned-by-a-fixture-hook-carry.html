Leg 14’s comment filter is pinned by a fixture hook carrying a commented control — KS-1746

What to know. preflight.sh:722 drops comment lines before leg 14 extracts the pre-push hook’s ${NAME:- control reads, so a control named only in a comment is never stripped from the suite run. On the shipped hook the only match is live code at .githooks/pre-push:77, so the filter changes nothing there — which is why the gate’s mutant G2 (delete the filter) survived preflight_deps.test.sh at 68/0.
Test file only: a third hook-stub mode (commented) on the existing preflight_fixture_run fixture, one extra reporting line in the fixture stub suite, and seven cells. preflight.sh is unchanged, sha256 identical before and after.
Two oracles. The announcement (the strip line must read exactly ALLOW_FORCE, asserted whole-line) and the behaviour read from the stripped side (FAKE=1 in the caller’s environment must still reach the suite). The second exists because the announcement is what mutant M3 proved leg 14 can fake.
Gotchas when you run this locally. Drive G2 as a matched pair, not a single arm. Six cells in this suite read above DEV_ROOT ($DEV_ROOT/../../.githooks/pre-push, the four slot-gateway cells, Projects Documents/PORT-REGISTRY.md), so pointing PREFLIGHT_DEPS_TEST_ROOT at a bare copy of Blockchain/Dev reddens them by relocation alone and reads 48/9 — three times G2’s real effect. Lay the copy out as a repo root (.githooks/, systemTest/, Projects Documents/ beside Blockchain/Dev) and run an unmutated control arm beside the mutant.
FAKE must be SET for the behavioural cell to mean anything. env -u on an already-unset variable is indistinguishable from not stripping it, so an unset probe reads <unset> on both arms. One cell pins that vacuity on purpose; do not “simplify” the FAKE=1 out of the arm above it. Also: the commented line in a fixture hook must start with # — a ${NAME:- in a trailing comment is not excluded by the filter.
Not measured here. The nit-3 read shapes (${NAME}, ${NAME:?}, bare $NAME) are still not stripped; filed as KS 1755. The four platform suites (Schemathesis, Akto, Playwright, Performance) are UNMEASURED, and no service unit suite was run because no service source is touched. Nothing on either box.
Noted, not fixed: the pre-existing nocontrol fixture mode does not model an empty derivation — its hook line does not start with #, so NAME is derived and the refusal fires on the missing ALLOW_FORCE instead. Same guard branch, so the cell still measures a real refusal.
