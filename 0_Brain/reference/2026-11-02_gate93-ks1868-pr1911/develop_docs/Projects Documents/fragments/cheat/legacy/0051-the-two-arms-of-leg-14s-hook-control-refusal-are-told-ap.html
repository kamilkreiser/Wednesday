The two arms of leg 14’s hook-control refusal are told apart by their Derived line — KS-1756

What to know. preflight.sh:731 refuses to run the shell suites when the derived set of the pre-push hook’s controls is empty or is non-empty but lacks ALLOW_FORCE. Both classify as HOOKCTL-REFUSED/1, so only the refusal’s own Derived: [...] line tells them apart. preflight_deps.test.sh now drives each arm with its own fixture mode — nocontrol (hook line starts with #, set is empty) and trailingcomment (the old line, NAME derived) — and asserts the line as a whole (grep -cxF).
Until this change nocontrol claimed the empty set and modelled the other arm, so a condition that let an empty derivation through passed the suite at 75/0. No product file changes.
Gotchas when you run this locally. Do not try to make a cell go red when the -z disjunct is deleted. It is redundant: for an empty set the second half of the condition is also true, so the deletion refuses on exactly the same inputs (a five-row truth table under bash 3.2 with pipefail; the matched-pair run reads 82/0 with zero cells moved). The cells pin the two mutants that are killable: M_accept (an empty set is accepted) by the empty arm, M_2nd (only -z remains) by the trailing-comment arm.
Drive mutants as a matched pair on a repo-root layout. Six cells in this suite read above DEV_ROOT, so a bare copy of Blockchain/Dev reddens them by relocation alone. git archive <base> | tar -x -C <dir> gives a complete layout; run an unmutated control beside each mutant and apply every mutation as an exact-string replace that aborts unless its anchor occurs exactly once.
The empty-arm hook line carries a ${NAME:- inside a # comment on purpose. Deleting the comment filter (G2) then derives NAME and turns the arm’s Derived line from [ ] to [NAME ], so G2 reddens two of these cells as well as KS-1746’s three. A hook line that is merely empty would not do that.
Not measured here. The four platform suites (Schemathesis, Akto, Playwright, Performance) are UNMEASURED, and no service unit suite was run because no service source is touched. Nothing on either box. The redundant -z disjunct is left in preflight.sh.
