125.3 What this does not prove

A guard made cheaper and louder, not a new check. The whole pre-push hook’s wall-clock before and after is not measured (that needs two pushes). How cold a seat’s node_modules is at push time varies with what the seat ran first, so the saving per push lies between the warm and cold figures above. The pattern the guard matches is unchanged; its coverage of other unsafe shapes is not assessed here. QA gate 35 found that the grep -v post-filter matches its words anywhere in a hit line, so product code in a path such as src/node_modules_shim/ is hidden, before and after this change (KS-1865); cell 5 pins that state, and flips when KS-1865 lands.
Not run: the four platform suites (Schemathesis, Akto, Playwright, Performance/k6), a running stack, any deploy.
