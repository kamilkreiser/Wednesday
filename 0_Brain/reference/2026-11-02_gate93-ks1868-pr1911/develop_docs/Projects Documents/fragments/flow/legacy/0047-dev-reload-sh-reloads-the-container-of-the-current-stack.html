58. dev-reload.sh reloads the container of the current stack slot, not slot 1’s (KS-1355)

What this changes. scripts/dev-reload.sh named its target container secuura-<service>, which is slot 1’s name, and never read stack_env.sh. With SECUURA_STACK_SLOT=2 it looked for slot 1’s container, and with slots 1 and 2 both running the new test records one restart of slot 1’s container where it wants none. The script now sources stack_env.sh and takes the name from ${STACK_PREFIX}; start-secuura.sh and stop-secuura.sh both source the same file (git grep over the tracked scripts).
This covers one of the two scripts named in spot 2 of KS-1355 (dev-reload.sh). It does not change start-local.sh, check-stack-safety.sh, the compose defaults, the preflight, or the shared-acceptance points on the ticket. git diff --numstat: dev-reload.sh 7 insertions and 1 removal, plus a new 99-line test file.
