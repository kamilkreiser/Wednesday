49. The formatting gate gives each package’s format:check its own empty stdin (KS-998)

What this fixes. check-package-format.sh walks the selected packages with while IFS= read -r p, fed by the here-string at its done <<< "$selected".
Each package ran npm run --silent format:check inside that loop, and npm hands its stdin to the script. A format:check that reads stdin drained the rest of the list: in the cells, the package after it was not checked, and a red package after it let the gate exit 0.
The call now ends < /dev/null, so each format:check reads an empty stdin and the loop keeps its list.

49.3 What the cells prove, and what they do not

Fixtures, not real prettier. The cells drive the gate through fixture packages whose format:check reads stdin on purpose. They show that a stdin-reading format:check no longer swallows the package after it.
They do not show that any real package’s format:check reads stdin: no real prettier ran against a real package here. The four platform suites (Schemathesis, Akto, Playwright, Performance/k6) are UNMEASURED and are not claimed as passing.
