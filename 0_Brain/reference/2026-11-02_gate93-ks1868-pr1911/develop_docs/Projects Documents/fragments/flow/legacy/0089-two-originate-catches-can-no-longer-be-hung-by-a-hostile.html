100. Two originate catches can no longer be hung by a hostile thrown value: the system-errors list and extractPgCode (KS-1780, part 1 and part 3)

What this changes. KS-1780 (originate): several catches read the thrown value before they reach fail500. A revoked Proxy, a Proxy whose getPrototypeOf trap throws, or an object whose getter throws makes that read throw from inside the catch, so the handler’s promise rejects and the request gets no response at all (the KS-1772 shape, one step earlier). This change closes two of the sites. In routes/systemErrors.ts the list route’s err instanceof z.ZodError becomes a new local isZodError(err), which returns false for a value that cannot be inspected. In utils/pgErrors.ts extractPgCode now wraps its reads of code, meta.code and message in a try and returns undefined if they throw (the old body is unchanged, renamed readPgCode); the PATCH /api/webhooks/:id catch calls it before fail500, and webhooks.ts itself is not edited. A value that cannot be read is not a ZodError and has no code, so the handler answers its constant 500. Two local-model passes (the Spark, DeepSeek V4 Flash: ks_1780_p1 and ks_1780_p3_webhooks) each passed their checker 7 of 7 and are byte-identical to the drafter’s golden; both were applied here strictly and unchanged.
