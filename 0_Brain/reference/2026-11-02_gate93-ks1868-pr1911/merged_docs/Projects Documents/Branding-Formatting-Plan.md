## 4. Formatting Specifications (Planned)

### 4.1 Cover Page Design

Each document will include a professional cover page with:
- Secuura logo (centred or top-right, per brand guidelines)
- Document title (primary heading font)
- Subtitle/description (secondary font)
- Version number and date
- Classification level (Confidential/Public/External)
- Secuura contact information
- Optional: Abstract or one-line summary

### 4.2 Standard Page Layout

| Element | Specification |
|---------|--------------|
| **Page size** | A4 (210 × 297 mm) |
| **Margins** | Top: 25mm, Bottom: 25mm, Left: 25mm, Right: 25mm |
| **Header** | Secuura logo (left), document title (centre), page number (right) |
| **Footer** | "Confidential — Secuura" (left), version/date (centre), page X of Y (right) |
| **Body text** | Per brand typography guidelines |
| **Line spacing** | 1.15–1.5 (per guidelines) |

### 4.3 Table Formatting

| Element | Specification |
|---------|--------------|
| **Header row** | Brand primary colour background, white text, bold |
| **Body rows** | Alternating white and light grey (or brand secondary) |
| **Borders** | Thin borders in brand accent or grey |
| **Status indicators** | Green for pass/compliant, amber for partial, red for non-compliant |

### 4.4 Section Formatting

| Element | Specification |
|---------|--------------|
| **H1** | Primary heading font, brand primary colour, page break before |
| **H2** | Primary heading font, brand secondary colour |
| **H3** | Body font bold, brand primary colour |
| **Body** | Body font, black/dark grey |
| **Code blocks** | Monospace font, light grey background, left border in brand accent |
| **Callout boxes** | Light brand colour background, left border in primary colour |
| **Links** | Brand accent colour, underlined |

### 4.5 Document-Specific Formatting

| Document | Special Formatting |
|----------|-------------------|
| **Compliance Report** | Compliance table with green ticks/red crosses; framework badges |
| **White Paper** | Professional cover with hero section; pull quotes; diagram styling |
| **Security Audit** | Severity badges (Critical=red, High=orange, Medium=yellow, Low=blue, Info=grey) |
| **Stakeholder Guides** | Step-by-step callout boxes; screenshot placeholders; "Tip" and "Warning" boxes |

## 6. Output Formats

Each document will be produced in two formats:

### 6.1 Word Document (.docx)

- Editable format for internal review and updates
- Embedded fonts (or web-safe alternatives)
- Track changes enabled for review workflow
- Named styles applied for consistency
- Table of contents linked to headings

### 6.2 PDF

- Final distribution format
- Fonts embedded
- Table of contents with clickable links
- Document properties set (title, author, subject)
- Optional: Password protection for confidential documents
- Optional: Watermark on confidential documents

## 7. Production Workflow

### Step 1: Receive Brand Assets
- Receive updated marketing guidelines and style guide from Secuura
- Extract all required brand elements (colours, fonts, logos, templates)

### Step 2: Create Document Templates
- Create Word document template (.dotx) with Secuura branding
- Configure styles (headings, body, tables, code, callouts)
- Create cover page template
- Create header/footer template

### Step 3: Convert Markdown to Branded Documents
- Convert each Markdown document to Word using the branded template
- Apply formatting and styles
- Insert logo, headers, footers
- Format tables and code blocks per brand guidelines
- Add cover pages and table of contents

### Step 4: Generate PDFs
- Export each Word document to PDF
- Verify formatting, links, and page numbers
- Set document properties

### Step 5: Quality Review
- Review all documents for:
  - Brand consistency
  - Typography correctness
  - Table formatting
  - Code block readability
  - Image/logo quality
  - Page numbering
  - Table of contents accuracy
  - Spelling and grammar

### Step 6: Final Distribution
- Place final documents in the Projects Documents folder
- Both .docx and .pdf versions for each document
