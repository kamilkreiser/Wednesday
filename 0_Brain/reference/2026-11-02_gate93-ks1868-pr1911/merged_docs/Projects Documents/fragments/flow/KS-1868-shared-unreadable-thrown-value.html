. shared unhandled-rejection listener and response-cache read keep logging when the thrown value is unreadable (KS-1868, packages/shared)

What this changes. Two reads of a thrown value in Blockchain/Dev/packages/shared: the unhandledRejection listener body createUnhandledRejectionHandler (src/utils/gracefulShutdown.ts) and the cache-read catch in responseCache (src/cache/response-cache.ts). Each read the value with X instanceof Error ? X.message : String(X) and no guard. If the value is a revoked Proxy, or an Error whose message getter throws, that read throws: the listener itself throws, so it never reaches its log or its shutdown call, and the cache middleware throws instead of falling through to next(). Each read now sits in an inner try with the fallback unreadable thrown value. The log text, the error key, the mode logic and the flow for any readable value are unchanged. Product bytes: +8/-2 and +7/-1.
Six new cells in two new files (ks1868-unhandled-rejection-handler-unreadable-reason.test.ts and ks1868-response-cache-read-unreadable-throw.test.ts, 3 cells each): a control that an ordinary Error still logs its message (C1) and red cells for a revoked Proxy (R1) and a throwing message getter (R2). Both product edits are held Spark passes (O38-P1, O38-P2) applied with strict git apply --check -p1 (rc 0 on all four sections, rc 1 on a copy with one context line's content corrupted); there is no hand edit.

.3 What this does not prove

Two reads, not the ticket. KS-1868 stays open: it lists 253 catch and log sites that read a thrown value unguarded; this change fixes two, both in packages/shared. Other instanceof Error reads in shared are not touched. response-cache.ts has no importer at this base (no index export, no exports entry, no wildcard), so its reach today is shared-internal.
Not run: the four platform suites (Schemathesis, Akto, Playwright, Performance/k6), a running stack or a booted api-gateway (so the effect on survive mode is the test author's reading of the code, not a measurement), Node 24 or any LTS Node, npm ci, any deploy.
