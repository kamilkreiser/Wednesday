14. Both observability env examples point the nginx status URI at :80 (KS-1388)

What this pins. Both commented examples of SECUURA_NGINX_STATUS_URI — in observability/.env.example and observability/config/alerting.env.example — suggested http://secuura-nginx-gateway:6882/stub_status. 6882 is the gateway's published HOST port and is not reachable from the exporter's network; the in-network port is 80, which is what observability/docker-compose.yml:331 already defaults to.
Both examples now say :80, so a reader who uncomments either line gets a URI that resolves on the compose network instead of one that cannot.
