40.3 Why a pin has no red at its base, and what the honest red is instead

A test that pins existing behaviour passes the moment it is written. So there is no red-before to quote, and quoting a green as if it were a red-to-green would be a false claim. The red for this row is the reverted tamper above: the pinned comparison is relaxed, the suite goes red on exactly the assertion that names the boundary, and the file is restored with its hash asserted. A 0 total / 0 failed reading would be a load failure and would prove nothing; the reading here is 3 total with 1 failed.
