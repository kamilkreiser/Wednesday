70. The KS-1347 proxy probe reads the subject’s imports as statements, not as one line shape (KS-1560)

What this pins. Blockchain/Dev/scripts/__tests__/ks1347_proxy_out_dir_spaced_checkout.test.sh plants the capture proxy’s OUT_DIR expression in a probe module and runs it. The probe inherits server.ts’s node: imports so that deleting one from server.ts reds the suite. The inherited set was read with grep -E "^import .* from 'node:[a-z]+';$", which saw the five lines server.ts has today only because of how it spells them. A harmless respelling made the set incomplete and reddened four cells while server.ts still worked.
The whole change is one file. The grep is replaced by a small extractor, extract_node_imports, that reads the import statement (either quote style, optional semicolon, a clause wrapped over lines, a trailing comment, CRLF, any node: specifier including node:child_process and node:fs/promises) and prints each in one canonical spelling. On the real server.ts it prints exactly what the old grep printed: five identical lines. server.ts is never edited (blob 306f8a1a4b5f before and after). .dockerignore:14 is **/__tests__, so the file reaches no image.
Twelve cells are added, and the suite goes from 8/0 to 20/0. The extractor is written into the fixture directory and used for the real subject and for eight synthetic spellings, a subpath/underscore case and three controls, so what is tested is what is used.

70.1 Respelling is harmless; deleting an import is not

The control that matters is kept and still fires. The existing cell that the inherited set is non-empty and names node:path and node:url is unchanged. Under the new suite it is red on all three deletion arms (the path import deleted, the url import deleted, all five deleted) and green on every respelling. The four cells the old grep wrongly reddened on a respelling are the same four that go red on a real deletion, so the suite did not lose a signal; it stopped raising a false one.
The old grep only reds when the missing import is one the expression needs. A trailing comment on the fs import left the old suite green at 8/0 (the expression does not use fs), while the same comment on the path import reddened it. That asymmetry is why a respelling can sit unnoticed until it lands on a needed line.
