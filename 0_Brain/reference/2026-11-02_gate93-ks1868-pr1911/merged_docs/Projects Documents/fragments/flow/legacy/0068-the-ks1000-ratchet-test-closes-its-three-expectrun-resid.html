79.2 Item 1: the guard counts depth, and steps over strings

The depth scan. runsComparedAsOneValue found an expect( argument opened by [ or { and read to the first ] or }. It now reads to the bracket that closes the one the argument opened, found by counting depth, so an index ahead of .status, an index ahead of .out, the object form with an index ahead of the second field, an index inside an index and an array of arrays are all seen. A value that never closes is scanned to the end of the text, as before.
Counting depth would read across the end of the value on a bracket inside a string, a false-positive class the old bound did not have. The scan steps over single-quoted, double-quoted and template-literal strings and honours a backslash. Eight forbidden and four permitted rows are added to the tables of shapes planted in a copy of the file; a quoted bracket and a template-literal bracket followed by a use of both fields are permitted shapes.
