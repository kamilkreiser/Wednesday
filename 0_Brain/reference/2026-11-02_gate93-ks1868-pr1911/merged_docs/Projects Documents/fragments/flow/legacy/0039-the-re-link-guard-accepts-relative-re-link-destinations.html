50. The re-link guard accepts relative re-link destinations and uid-0 users with a group (KS-937)

What this fixes. Two false BLOCKs in Blockchain/Dev/scripts/check-shared-relink.sh, assertion A (the re-link invariant). This carries KS-937 items F-C and F-E; F-A, F-B, F-D and F-F are untouched and the ticket does not move to Done.
F-C: the re-link destination had to be node_modules/… or an absolute /…/node_modules/…, so ./node_modules/@secuura/shared and app/node_modules/@secuura/shared read as “final stage has NO re-link”. The prefix group no longer requires a leading slash.
F-E: USER root:root and USER 0:0 were compared whole, so they read as non-root and the re-link after them was refused on the privilege rule. The :group part is now dropped before the comparison, when a user part is present.

50.1 One deviation from the Spark payload

Ruled, one line. The payload dropped :group unconditionally. For USER :root (an empty user part) that left an empty value, which the guard treats as root. Nothing has measured that USER :root runs as root, or that Docker builds it, so the group is dropped only when a user part is present (if (u !~ /^:/)) and one cell pins USER :root to the privilege refusal.

50.3 What the guard still refuses (the widening, measured)

Refused by both: a wrong package name, a wrong source, a hard link, a link before the last node_modules write, a link after USER secuura, no link, and USER secuura:root, 1000:0, node:node, rootless:root, root0:root, :root, :0, ${UID}:${GID}. The 66 refusal cells declared in the base suite (static count: expect 28, row_case 31, nonjs_case 7) all pass at the head, 66 of 66.
A measured gap, not fixed here: ../node_modules/@secuura/shared (the parent of WORKDIR) is newly accepted. The guard has not checked that the destination is the stage’s own node_modules: an absolute wrong place such as /tmp/node_modules/… already passed at the base. Checking location needs WORKDIR resolution.
