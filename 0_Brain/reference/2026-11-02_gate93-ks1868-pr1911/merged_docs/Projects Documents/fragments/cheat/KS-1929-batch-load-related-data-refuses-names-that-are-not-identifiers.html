batchLoadRelatedData refuses a model or related field that is not a plain SQL identifier — KS-1929, shared

What to know. batchLoadRelatedData(prisma, model, relatedField, parentIds) writes model and relatedField into the SQL text (identifiers cannot be bound), so both must match ^[A-Za-z_][A-Za-z0-9_]*$, be strings, and be at most 63 characters; otherwise it throws Invalid SQL identifier before any query, with no part of the refused value in the message. parentIds stays bound. A schema-qualified name (public.documents) is refused. Valid calls are unchanged: same SQL text, same grouped result.
Not measured here. Callers outside this repository (the package is publishable). A real database. getOptimizedCount (a different shape) was not changed. The four platform suites, an LTS Node and any deploy were not run.
