The KS-1347 proxy probe inherits server.ts’s imports by statement, so the respellings it reads no longer red it — KS-1560

What to know. ks1347_proxy_out_dir_spaced_checkout.test.sh copies server.ts’s node: imports into a probe so that deleting one reds the suite. They were read with a one-line grep that matched only import X from 'node:[a-z]+'; at the end of a line. Double quotes, a missing semicolon, extra spaces, a wrapped list, a trailing comment, CRLF or node:path/posix each made the set incomplete and reddened four cells while server.ts worked.
The grep is now extract_node_imports, written to the fixture directory and run on the real subject and on eight synthetic spellings. 20/0 from 8/0. A real deletion of an import still reds, and the control that the set is non-empty and names node:path and node:url still fires on an emptied list. server.ts is not edited.
Gotchas when you run this locally. Respell a COPY, in a mini-tree. The suite reads its subject only as $HERE/../openapi-examples/proxy/server.ts, so scripts/__tests__/<suite> beside scripts/openapi-examples/proxy/server.ts in a temp directory is a complete harness. Run the old and the new suite on the same copy; the old suite reads 4/4 on every respelling of an import the expression needs.
A respelling only reds the old suite when it lands on an import the expression needs. A trailing comment on fs left it green at 8/0 because the expression does not use fs. Put the respelling on path or url. And node --check cannot parse TypeScript here (const x: string fails), so validate a respelling on the import block alone as a .mjs file; the suite does this and has a control that a broken import is rejected.
Count rows against arms. A matrix driver that reads its arm list with while read silently drops the last arm if the file has no trailing newline. The first run printed 10 rows for 11 arms and was caught only by that comparison.
Not measured here. The four platform suites (Schemathesis, Akto, Playwright, Performance) are UNMEASURED; no service unit suite was run; nothing on either box. The suite’s OUT_DIR extraction (grep -E '^const OUT_DIR') is the same class: wrapping the line after ?? or writing export const reddens 5 cells in both suites. Measured, not changed.
