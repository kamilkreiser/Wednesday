Akto reports carry no credentials; Akto 2.41.6 — KS-1608

What to know. Every file and page the Akto harness writes is masked through one module, systemTest/akto/src/core/redact.ts: report.json, the HTML report, curl reproducers, service logs, threads.txt and exception messages. Credential headers, JWTs, Bearer tokens, sk_ keys, credential JSON fields and ?token=-style parameters become ***. Ids, hashes, wallet addresses and non-credential headers stay, so a finding is still reproducible. To reproduce with a credential, mint a fresh token on the slot; the report will never hold one.

Full coverage. test:security now selects every template Akto will run: 213 ids / 21 categories at 2.41.6. Akto’s 19 active built-in sensitive-data checks (SENSITIVE_DATA_EXPOSURE_*, passive) are catalogued, and the six templates Akto switched off on 2026-10-25 for another account’s false positives are switched back on (src/setup/reenabledTemplates.ts). load-templates fails if any of the six is not active; test:setup fails on any active template the catalog omits.
