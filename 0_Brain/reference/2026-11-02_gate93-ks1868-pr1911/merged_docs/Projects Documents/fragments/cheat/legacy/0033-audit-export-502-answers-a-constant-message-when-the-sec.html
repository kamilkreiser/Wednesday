audit-export 502 answers a constant message when the security service is unreachable — KS-1410

What to know. GET /api/admin/audit/export, when the fetch to the security service throws, answers 502 BAD_GATEWAY with the constant message Failed to reach security service. It used to append the thrown text, in every environment.
The detail is in the log now. api-gateway logs Audit export could not reach the security service (GET /api/admin/audit/export), with the error reduced by Kam's 2026-09-27 ruling: an Error's message and a thrown string as they are, an object as its type and field names.
Unchanged. An upstream that answers non-ok still passes its own status and error through (cell XC1), and a request with no user still answers 401 without a fetch (XC3).
Gotcha when you run this locally. (1) npx tsc --noEmit in api-gateway does not type-check src/__tests__: its tsconfig excludes them, and its program listed 0 of this test file. Type-check a test with a program that lists it.
