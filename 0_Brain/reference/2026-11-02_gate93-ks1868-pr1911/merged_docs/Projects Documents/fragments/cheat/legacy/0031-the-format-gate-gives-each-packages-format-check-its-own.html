The format gate gives each package’s format:check its own empty stdin — KS-998

What to know. check-package-format.sh reads its package list in a while read loop, and npm hands that stdin to each format:check.
A format:check that read stdin drained the list, so the package after it was not checked, and a red one there let the gate pass (cell drain-then-red: exit 0 at the base).
The call now ends < /dev/null. This is the ticket’s robustness note: items 1–3 stay open and the ticket does not move to Done.
Gotcha when you run this locally. The cells use fixture packages whose format:check reads stdin on purpose; they say nothing about whether a real package’s does.
Expect the shell-suite denominator to read 74 at this head, not 73.
