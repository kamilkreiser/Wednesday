RFC 3161 Timestamp Verification — KS-1404

What to know.POST /api/timestamps/verify used to accept an unsigned token: any DER blob containing the document digest read as valid, and a JSON {"hash":"…"} token read as valid too.
Both paths are closed.
Verification now checks the CMS signature over TSTInfo, the signed messageDigest, EKU id-kp-timeStamping, validity at genTime, and a chain to a configured trust anchor — and reads the imprint from the parsed TSTInfo rather than searching the tree.
