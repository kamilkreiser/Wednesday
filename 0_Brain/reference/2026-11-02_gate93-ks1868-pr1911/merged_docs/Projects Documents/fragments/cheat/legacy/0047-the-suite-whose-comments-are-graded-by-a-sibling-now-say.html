Gotchas when you run this locally. Do not quote the graded sentence in your own comment. CELL 2 counts occurrences across the WHOLE file and asserts -eq 1, not -ge 1. So a paraphrase reds it at 0 hits and a helpful quotation reds it at 2. Describe the strings by role instead; have your patch script assert the three counts are (0, 1, 1) afterwards and refuse to write if they moved.
Red-proof through HOOK_BASE_SUITE=/path/to/copy, never by editing the shipped file. It refuses an empty value (rc 2) rather than silently grading the shipped one, so an unset-versus-empty slip cannot pass as a run.
Read exit codes on their own line, not through a pipe. The refusal arm read rc 0 through | tail — that is tail’s status. Re-measured bare it is rc 2. Same trap applies to the red arm (rc 1) and the green arm (rc 0).
