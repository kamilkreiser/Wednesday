OAuth app scopes and ownership — KS-1210

What to know. Any authenticated user could register an OAuth app, or change someone else's, with any scope list including * and subjects:erase.
Two gates now apply. Gate 1: both schemas are closed to the nine published AVAILABLE_SCOPES — anything else is 400 for everyone — and admin:read / admin:write additionally need the four-role platform list, else 403. Gate 2: the four by-id routes answer 404 unless you created the app or hold one of the six admin roles.
404, not 403, so the status code does not disclose someone else's app.
