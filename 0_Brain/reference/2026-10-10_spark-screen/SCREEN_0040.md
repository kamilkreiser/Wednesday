## Harness findings

1. **Selection has no prior-art gate.** Nothing in `build_input.sh`, `round.sh` or `brief_lint.py` stops a brief for a ticket that already has a PASS 7/7 held READY (`spark/done.md`, `night/READY_*`). I wrote KS-1432 before finding the 10-07 PASS. A `done.md`/READY lookup by ticket number belongs in the screen, and could be a lint warning.
2. **A code_patch2 brief needs a `File:` line under `## The test`** naming a DECLARED test. With only `Test file:` lines the builder picks a title-slug test path and `build_input2.sh` refuses (`suggested_test_file … is not among the declared tests`). First dry run refused for exactly this; fixed in the brief. The templates do carry that line (rung 4); the failure message is accurate but the cause is easy to miss.
3. **Large product files need `ctx=`.** A 74 KB file carried whole gives ~29K prompt tokens at the default `num_ctx` 32768 and the builder warns (only a WARNING, rc 0). Pinned `ctx=65536` in `spark.pins`. The 160000 B excerpt trigger is high; a loose brief on a big file is therefore always a big prompt.
4. **A4 needs ASSERTION reds, so "the export is missing" must be asserted, not called.** `checker.sh` (A4, PY4) counts a failure only if its message holds `AssertionError` or an `expect(` frame; a `TypeError: x is not a function` would read as a non-assertion red and fail A4. The new KS-1432 test asserts `typeof exported` first (the `ks1071` C6 house pattern).
5. **Non-ASCII context lines are a hazard.** `ascii_proxy` exists only for '-' lines. `ks529-non-object-body-guard.test.ts` holds `→` and `—` on lines the default 3-line context would include; the golden hunks for that file were cut at `-U1` so no context line is non-ASCII.
6. **Prose briefs leave A3b with nothing to enforce.** KS-1345 has no `## Where`, so the input's `sites` is `[]`, A3c's expected set is `[]`, and the only site datum is `line=414`, which the builder prints into the model's note ("reach the defective code at line 414"). So a rung 6 here is "no line number in the brief", not "none in the prompt". Also the brief's `## Premises` is part of the prompt and names files and lines; I flagged this in the brief (a purer rung 6 would strip it before queueing).
7. **`build_input.sh` header is stale**: it says originate/governance (jest) are refused; the code accepts jest (since 09-15). **`fleet/board_count.sh` cannot count above 250** (no pagination, no way to raise the page).
8. **jest once-queues survive `jest.clearAllMocks()`**: a `mockRejectedValueOnce` left unconsumed leaks into the next cell. KS-1345's D4 deliberately arms nothing (noted in the brief).
